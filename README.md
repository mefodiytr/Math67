# 🌙 Феликсия — Академия Девяти Лун

> **Курс математики 6+ → 7–8 класс**, оформленный как магическое приключение.
> Русская школа · Cambridge Lower Secondary · олимпиадное мышление — в одной программе.

Лене 12. Через 13 модулей и 183 урока она пройдёт от **дробей** до **квадратных уравнений**, **доказательств** и **функций**. Каждый модуль — остров. У каждого острова — Хранитель, ученица, испытание и **Лунный Камень** в финале. Девять Камней + Перо + Кристалл + Печать — и Лена готова к сильному 7–8 классу и Cambridge Checkpoint.

## 📖 Куда идти за чем

Курс состоит из **четырёх параллельных слоёв**, синхронизированных по урокам.

| Слой | Куда | Что внутри |
|---|---|---|
| 📖 **Уроки** для ученицы | [`lessons/`](lessons/) | Полный конспект каждого урока: сюжет, теория, задачи 4 уровней, English, домашка с ответами |
| 👩‍🏫 **Методички** для учителя | [`teacher-guides/`](teacher-guides/) | Тайминг 90 минут, типичные ошибки, шкалы 1–5, дневник прогресса |
| 🎨 **Презентации** (описания + промты) | [`lesson-presentations/`](lesson-presentations/) | Описание каждого слайда + GPT Image-промт для иллюстрации |
| 📦 **Готовые .pptx** | [`slides/`](slides/) | PowerPoint-файлы, собранные из описаний |
| 📜 **Сюжетные арки** | [`stories/`](stories/) | По одной арке на модуль — вселенная, локации, Хранители |
| 🗺️ **Описания модулей** | [`modules/`](modules/) | Что учим, темы, цели, Cambridge-блок, контроль |
| 🖼️ **Атомы графики** | [`assets/`](assets/) | Промты для персонажей, артефактов, локаций, эмблем |
| 🎭 **Стилевод курса** | [`world-bible.md`](world-bible.md) | Палитра, тон, диалоги, мифология |
| 🌐 **Интерактивный сайт** | [`web/`](web/) | Astro 4 + React. Деплой на [9moons.30000.ru](https://9moons.30000.ru) |

### Один урок = пять файлов

## 📐 Формат одного урока

Каждый урок — **строгий шаблон** (90 минут):

```
┌─────────────────────────────────────────┐
│  1. Сюжет (где Лена, кто рядом)         │
│  2. Что узнаём сегодня                  │
│  3. Идея + метафора из мира             │
│  4. Пример (от лица персонажа)          │
│  5. ★    Core      — 6–10 задач         │
│  6. ★★   Strong    — 8–12 задач         │
│  7. ★★★  Advanced  — 4–6 задач          │
│  8. ★★★★ Sphinx    — 1–2 олимпиадных    │
│  9. 🔔  English with the Bell Fairy     │
│ 10. 🐾  Кошачий факт / миф              │
│ 11. Рефлексия (3 вопроса)               │
│ 12. 🌙  Домашний квест + бонус          │
│ 13. Ответы под спойлером                │
└─────────────────────────────────────────┘
```

Параллельно в методичке — тайминг по частям, разбор сложных мест, типичные ошибки и три уровня поддержки.

## 🚀 Как пользоваться курсом

### Учитель

1. Открой [`modules/`](modules/) и выбери текущий модуль.
2. Прочти арку в [`stories/`](stories/) — это «крючок» для ребёнка.
3. На занятии:
   - Открой `lessons/module-NN/lesson-MM-*.md` — конспект.
   - Параллельно держи `teacher-guides/module-NN/lesson-MM-guide.md`.
   - Презентация: либо готовый `.pptx` из `slides/`, либо собери по описанию из `lesson-presentations/`.
4. После урока — заполни шкалы 1–5 в дневнике методички.
5. После финала модуля — обнови «карту навыков» (она в финальном уроке).

### Ученица (Лена)

1. Сюжетный hook читает учитель.
2. Решает по уровням: ★ → ★★ → ★★★ → (★★★★ по желанию).
3. English-блок обязателен.
4. Дома — 4–5 задач + бонус-квест (рисунок / эссе / ребус).

### Родитель

- Каждые 3 месяца — большой mixed-test (см. соответствующий модуль).
- Карта навыков обновляется учителем после **финала** каждого модуля.
- В финале курса (Модуль 12) — **сертификат Адепта Девяти Лун**.

## 📜 Лицензия и тон

Курс разработан **для конкретной ученицы (Лена)** и не предполагает массового распространения. Все персонажи, тексты, схемы — авторские. Японско-китайские мифологические имена использованы в духе **уважения и культурной точности**.

- ❌ Гендерных стереотипов («ты же девочка...»).

- ❌ Сахарных восклицаний.

- ✅ Лёгкая магическая образность.
- ✅ Кошачьи метафоры в объяснении математики.
- ✅ Японско-китайские термины **с переводом**.
- ✅ Юмор на уровне характеров.
