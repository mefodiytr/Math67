# Презентация — Модуль 0. Диагностика и математический профиль ученика

**Формат:** 16:9, 11 слайдов, ~25–30 минут.
**Целевая аудитория:** ученик 6+ класса, занимающийся по русско-Cambridge программе.
**Общий стиль:** см. раздел *«Единый визуальный стиль курса»* в `README.md`. Префикс стиля используется во всех промтах ниже.

**Описание:** объясняет смысл модуля без скучных фраз про «проверим знания».

**Текст:**

## Технические заметки

- Каждый слайд должен помещаться в 16:9 при чтении за 1.5–3 минуты.
- На каждый слайд — **один главный визуальный элемент**, не больше.
- Для генерации изображений в GPT Image **обязательно** добавлять `style prefix` из README.
- Если изображение должно содержать математические символы (1, 2, x, π), писать в промте *“with crisp clearly readable digits/symbols”*, а формулы — лучше **набирать поверх изображения в редакторе слайдов**, не доверяя их генератору.
