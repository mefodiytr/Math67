# presentations/ — обзорные презентации модулей

Здесь лежат **обзорные презентации каждого модуля** в формате MD-описания слайдов.

Это «макропрезентация модуля» — для введения и финального обзора, **не для каждого урока**. Поурочные презентации — в [`../lesson-presentations/`](../lesson-presentations/).

## Что в файле описания слайда

Каждая обзорная презентация — около 12 слайдов. На каждый слайд:

- **Описание** — что и зачем.
- **Текст** — содержимое слайда.
- **Инфографика** — что должно быть нарисовано.
- **Стиль** — палитра, акценты.
- **Промт GPT Image** — готовый промт для генерации иллюстрации.
