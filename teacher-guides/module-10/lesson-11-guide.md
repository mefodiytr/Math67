# Методичка к уроку 10.11 — «Работа»

## Цели
1. A=p·t, общая работа = 1.
2. p_совм = p₁+p₂.
3. Формула ab/(a+b).

## Решения
**Core:** 1/8 / 3 / 3/10 / меньше.
**Strong:** 3 / 3 / 6 / 6.
**Advanced:** ab/(a+b) / зависит от b.
**Sphinx:** 12.

## English: 4 / сумма / договор.

## Где «ломается»
1. Складывают **времена** вместо производительностей.
2. Не принимают работу за **1**.
3. Считают **двух** = **2× быстрее одного** (только при равных).
