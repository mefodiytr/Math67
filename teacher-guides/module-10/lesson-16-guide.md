# Методичка к уроку 10.16 — «Обратный ход»

## Цели
1. Метод «от ответа».
2. Лишние / недостающие данные.
3. Аккуратное обратное действие.

## Решения
**Core:** 80 / 150 / вес / тип.
**Strong:** 300 / 9 / 15 / 3 ч.
**Advanced:** 400 / достаточно vs нужно.
**Sphinx:** 80.

## English: 300 / 5 / лишние.

## Где «ломается»
1. Не **разворачивают** операции.
2. **Используют все** данные «на всякий».
3. Не задают вопрос «что **нужно** для ответа».

## Дневник
```
Урок 10.16
Обратный ход:                         [1 2 3 4 5]
Лишние данные:                        [1 2 3 4 5]
Недостающие данные:                   [1 2 3 4 5]
```
