# Методичка к уроку 10.3 — «Проценты»

## Цели
1. 3 типовые задачи.
2. Изменение через множитель.
3. Ловушка «+p% и −p%».

## Решения
**Core:** 20 / 20% / 200 / 60%.
**Strong:** 400 / 1000 / 25% / 500.
**Advanced:** вернулась / +21%.
**Sphinx:** 105.

## English: 70 / 30% / нет.

## Где «ломается»
1. Считают +p% и −p% **симметрично**.
2. Не используют **множитель** (1 ± p/100).
3. Берут % от **неправильного** целого.

## Дневник
```
Урок 10.3
Часть / целое / %:                    [1 2 3 4 5]
Множитель ±%:                         [1 2 3 4 5]
Многократное изменение:               [1 2 3 4 5]
```
