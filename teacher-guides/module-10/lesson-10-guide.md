# Методичка к уроку 10.10 — «Средняя скорость»

## Цели
1. v_ср = S_общ / t_общ.
2. (v₁+v₂)/2 — только при равном времени.
3. Гармоническое для равных путей.

## Решения
**Core:** 53.3 / 60 / 6.67 / время равно.
**Strong:** 48 / 50 / 5 / 25.
**Advanced:** 45 / 50.
**Sphinx:** 10.

## English: 48 / 50 / разное время.

## Где «ломается»
1. Берут **среднее арифметическое** скоростей всегда.
2. Не различают «**половина пути**» и «**половина времени**».
3. Не делят S/t.

## Дневник
```
Урок 10.10
v_ср = S/t:                           [1 2 3 4 5]
Гармоническое среднее:                [1 2 3 4 5]
Половина пути / времени:              [1 2 3 4 5]
```
