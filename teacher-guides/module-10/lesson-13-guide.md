# Методичка к уроку 10.13 — «Смеси»

## Цели
1. Сохранение вещества.
2. c = вещество/масса.
3. Правило креста.

## Решения
**Core:** 5 / 1 / 20% / та же.
**Strong:** 30% / 200 г / 100 г / 50%.
**Advanced:** 1:1 / 100 г.
**Sphinx:** 80%.

## English: 42% / 100 г / 1:1.

## Где «ломается»
1. Складывают **проценты**.
2. Не **переводят** в массу вещества.
3. Не учитывают **рост массы** при добавлении.

```
Урок 10.13
c = вещество/масса:                   [1 2 3 4 5]
Сохранение вещества:                  [1 2 3 4 5]

```
