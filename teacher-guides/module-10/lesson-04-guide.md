# Методичка к уроку 10.4 — «Покупки»

## Цели
1. Стоимость / сдача / НДС.
2. Сравнение акций.
3. Проверка разумности чека.

## Решения
**Core:** 240 / 40 / 750 / 70.
**Strong:** 180 / 8 / 320 / ≈66.67.
**Advanced:** 500 / B (2000 < 2100).
**Sphinx:** Завышение 10₽/шт.

## English: $12 / $15.50 / buy-2-get-1.

## Где «ломается»
1. Не пересчитывают **сдачу** в обратном порядке.
2. Сравнивают акции **на разном** числе товаров.
3. Не понимают «**купи 2 — третий бесплатно**» как 33.3%.
