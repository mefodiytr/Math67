# Методичка к уроку 8.7 — «Дирихле I»

## Цели
1. Принцип ящиков.
2. Применение к месяцам/дням/носкам.
3. Геометрический принцип Дирихле.

## Решения
**Core:** 1) 2. 2) 2. 3) 8. 4) 9. 5) 5.
**Strong:** 6) ✓. 7) 4. 8) 11. 9) ✓.
**Advanced:** 13) 12.
**Sphinx:** 3 / 4 / зависит.

## English: 2 / 4 / 4.

## Где «ломается»
1. **Без «минимум»** — точная цифра, которой нет.
2. **«13 предметов в 12 = 13/12»** — нет, *⌈13/12⌉ = 2*.
3. **Носки**: считают пары неправильно (нужно цветов + 1).
