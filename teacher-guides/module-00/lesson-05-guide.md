## Где обычно «ломается» ребёнок

1. **Задача 8** даёт **нецелое x = 20/3**. Многие ребята считают это «ошибкой» и пытаются «дорешать». Объясни: уравнения **не обязаны** иметь целые корни.
2. **Задача 9.** Знак: *(a − b)² − (a + b)² = −4ab*. Знак «минус» — главная ловушка.
3. **Задача 10 (ratio + разница).** «5k − 3k = 6» — вместо «5k = 6 + 3k» или подобного хаоса.
4. **Задача 12.** Снова «+25% −20% = +5%» — нет, **0%**.
5. **Задача 17 (внешний угол).** Дети пишут *«внешний = 60°»*, забывая про второй несмежный.
6. **Задача 19 (доказательство).** Многие пишут «1+2+3 = 6 делится; 4+5+6 = 15 делится; значит всегда». Это **проверка**, не доказательство.
7. **Задача 20 (шуточная).** Это **тест на критическое мышление**. Если ребёнок честно сказал «условие странное» — **отлично**. Если попытался формально решить — тоже отлично, главное — **рассуждение**.
8. **Задача 22 (Sphinx).** Ребёнок может перебирать «в лоб». Это нормально. Главное — **методичность**.
9. **English (b) и (c).** Ребёнок может посчитать (a) и не понять, как «упростить» отношение в (b). Подскажи: «*9 : 10* — это и есть простейшая форма».

## Подробные решения

### Часть I

| # | Решение | Ответ |
|---|---------|-------|
| 1 | 8 + 56 − 12 | **52** |
| 2 | (5/12)·96 = 5·8 | **40** |
| 3 | 7/9 ≈ 0.778; сравни с 0.78 | **0.78 больше** |
| 4 | 0.18·250 | **45** |
| 5 | 700/7 = 100; 3·100, 4·100 | **300 и 400** |
| 6 | 1.2x = 360 | **x = 300** |

### Часть II

**7.** *4(2x−5) − 3(x−7) = 8x − 20 − 3x + 21 = **5x + 1**.*

**8.** *5(x−1) = 2(x+4) + 7*
*5x − 5 = 2x + 8 + 7*
*5x − 5 = 2x + 15*
*3x = 20*
*x = 20/3 ≈ 6.67.*

**9.** *(a−b)² − (a+b)² = −4ab.* При a=5, b=2: *−40*.

**10.** *5k − 3k = 6 → k = 3 → всего 5k + 3k = 8k = 24.*

**11.** При a=6: *3x = 6 → x = 2.* При x=0: *a = 12.*

**12.** *1.25 · 0.80 = 1.00 → **0%**.*

### Часть III

**13.** Доли 2 + 3 + 4 = 9. *180/9 = 20°*. Углы: **40°, 60°, 80°**.
**14.** S = 40 см², P = 26 см.
**15.** S = ½·6·4 = **12** (треугольник с катетами 6 и 4).
**16.** S = π·36 ≈ 113.04 см²; C = 12π ≈ 37.68 см.
**17.** Внешний 130° = первый несмежный (60°) + второй (70°). Третий = 180 − 130 = 50°. Углы: **60°, 70°, 50°**.
**18.** S × 4 ⇒ сторона × **2** (масштабное правило: ×k², k = 2).

### Часть IV

**19.** *n + (n+1) + (n+2) = 3n + 3 = 3(n+1).* Делится на 3. ✓

**20.** Это шуточная задача-ловушка. Принимай **любое осмысленное** рассуждение:
- *«Шерсть нельзя посчитать в свитках, поэтому условие некорректно».*
- *«Если предположить, что “шерсть” — единица, то одна шерстинка = свиток. У Цукико → 1 свиток. У Лены = 3 свитка. Всего 4. Но в условии 30. Значит, единица должна быть 7.5 — это не натуральное число. Условие невозможно».*
Любой обоснованный ответ — **отлично**. Это диагностика **не математической, а критической** мысли.

**21.** P = 2(2x + (x+3)) = 6x + 6; S = 2x(x+3) = 2x² + 6x.
При x = 5: **P = 36, S = 80**.

### Sphinx Final №22

*5a + 8b = 100.* Перебор по *b*:
- b = 0 → a = 20.
- b = 5 → a = 12.
- b = 10 → a = 4.
- Другие *b*: 5a даёт 100 − 8b, должно быть положительно и кратно 5. *8b mod 5* = 3b mod 5; чтобы 100 − 8b ≡ 0 mod 5, нужно 8b ≡ 0 mod 5, т.е. 3b ≡ 0 mod 5, т.е. b ≡ 0 mod 5.

→ b ∈ {0, 5, 10}.

**Если в задаче требуем «оба вида монет» (a, b ≥ 1):**
b = 5: a = 12 ✓.
b = 10: a = 4 ✓.
**2 способа.**

**Если разрешаем нулевые:**
**3 способа** (включая b = 0).

> Принимай оба варианта. Главное — **системность перебора**.

## English block — разбор

**Task. (a)** *3 + 5 = 8 частей. 32/8 = 4. Красные = 12, синие = 20.*
**(b)** Стало 12 + 6 = 18 красных, 20 синих. *18 : 20 = 9 : 10*.
**(c)** Ожидаемое объяснение:
*“I divided 32 into 8 equal parts of size 4. Red = 12, blue = 20. After adding 6 more red, the new ratio is 18 : 20, which simplifies by dividing both by 2 to 9 : 10.”*

> **Что наблюдать.**
> – Если ребёнок вообще пытается объяснить **по-английски** — это уже 4/5.
> – Если объяснение чёткое и со словами *“divided, simplifies”* — 5/5.
> – Если объясняет по-русски, но логика правильная — 3/5 за English, 5/5 за reasoning.
