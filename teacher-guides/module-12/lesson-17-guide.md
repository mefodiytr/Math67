# Методичка к уроку 12.17 — «Параметр»

## Цели
1. Случаи параметра.
2. Min/max на параболе.
3. Дискриминант (упоминание).

## Решения
**Core:** a=0 / зависит / нет / 3/a.
**Strong:** разбор / разбор / 4 / 1.
**Advanced:** ±2 / −2 < k < 2.
**Sphinx:** a = 4.

## English: 3 / 5/a / 3.

## Где «ломается»
1. Не разбирают **случаи**.
2. Делят на **0**.
3. Не используют вершину параболы.
