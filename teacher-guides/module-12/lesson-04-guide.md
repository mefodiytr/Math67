# Методичка к уроку 12.4 — «Степени»

## Цели
1. 7 свойств.
2. a⁰ = 1, a⁻ⁿ = 1/aⁿ.
3. Применение в выражениях.

## Решения
**Core:** 32 / 125 / 81 / 100.
**Strong:** x⁷ / y³ / a⁷ / 2.
**Advanced:** 8x⁶y³ / 16.
**Sphinx:** анализ.

## English: x⁸ / 64 / 2⁻⁴.

## Где «ломается»
1. Перемножают **степени** при +.
2. Не помнят a⁰ = 1.
3. Боятся отрицательной.
