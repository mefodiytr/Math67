# Методичка к уроку 12.12 — «Системы (графика)»

## Цели
1. Графический метод.
2. 3 случая.
3. Чтение точки.

## Решения
**Core:** (2,2) / (2,4) / (4,5) / нет.
**Strong:** (2,3) / (0,0) / (5,3) / 0.
**Advanced:** (2,2) / (3,2).
**Sphinx:** a = −1.

## English: (2,2) / 0 / парал.

## Где «ломается»
1. Не строят **обе** прямые.
2. Не различают параллель и совпадение.
3. Округляют точку.
