# Методичка к уроку 12.8 — «Вынесение»

## Цели
1. Общий множитель.
2. Группировка.
3. Деление многочлена на (x−a).

## Решения
**Core:** 3(x+2) / 5(y−2) / 4(x+2y) / x(x+1).
**Strong:** 2x(x²−2x+3) / 3ab(2a+3b−1) / (x+1)² / (x−2)(x²+3).
**Advanced:** (x−1)(x+1)² / (a+b)(x+y).
**Sphinx:** (a−3)(a²+3a+8).

## English: 4(x+3) / 3xy(2x−3y) / (a+b)(x+y).

## Где «ломается»
1. Не **видят** общий множитель.
2. Берут **не наименьшую** степень.
3. Не пробуют **группировку**.
