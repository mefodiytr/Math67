# Методичка к уроку 12.5 — «Раскрытие»

## Цели
1. FOIL.
2. (a+b)², a²−b², (a+b)³.
3. Тройное произведение.

## Решения
**Core:** x²+3x+2 / x²+3x−4 / a²−b² / x²−7x+10.
**Strong:** 2x²+5x+3 / 2x²−x−15 / a²−4b² / 9x²+6x+1.
**Advanced:** x³+6x²+11x+6 / a³+3a²b+3ab²+b³.
**Sphinx:** 11.

## English: 3 раскрытия.

## Где «ломается»
1. Забывают **средний** член (2ab).
2. Путают знаки.
3. Не группируют.
