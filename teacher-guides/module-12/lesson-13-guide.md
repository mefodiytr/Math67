# Методичка к уроку 12.13 — «Системы (алгебра)»

## Цели
1. Метод подстановки.
2. Метод сложения.
3. 3 неизвестных.

## Решения
**Core:** (2,3) / (3,6) / ∞ / (3,4).
**Strong:** (6,4) / (3,1) / (4,8) / (2,3).
**Advanced:** (2,3) / (34/11, 53/11).
**Sphinx:** (2, 3, 4).

## English: (5,3) / (3,9) / (2,1).

## Где «ломается»
1. Не **выражают** одну через другую.
2. Знаки при сложении.
3. Не подставляют **обратно**.
