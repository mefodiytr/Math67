# Методичка к уроку 12.3 — «Выражения»

## Цели
1. Подобные слагаемые.
2. Раскрытие скобок.
3. Сокращение.

## Решения
**Core:** 6x / 4y / 6x+2y / 2x+6.
**Strong:** x−8 / x²+5x+6 / x²−1 / 2x²+xy−3y².
**Advanced:** 6x² / a²+2ab+b².
**Sphinx:** x+2.

## English: 3x+3 / x²+2x−8 / 2a+6b.

## Где «ломается»
1. Складывают **разные** буквы.
2. Не следят за **знаками** перед скобкой.
3. Забывают про **−1** в раскрытии.

## Дневник
```
Урок 12.3
Подобные:                             [1 2 3 4 5]
Раскрытие:                            [1 2 3 4 5]
Сокращение:                           [1 2 3 4 5]
```
