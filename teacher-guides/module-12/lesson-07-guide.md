# Методичка к уроку 12.7 — «Разность квадратов»

## Цели
1. a²−b² = (a−b)(a+b).
2. Быстрый счёт.
3. Двойное применение для x⁴−16.

## Решения
**Core:** (x−3)(x+3) / ... / (2−a)(2+a) / (x−1)(x+1).
**Strong:** (2x−3)(2x+3) / (5−x)(5+x) / (x²−4)(x²+4) / 9999.
**Advanced:** 12x / 4n²−1.
**Sphinx:** {(±5,±3), (±4, 0)}.

## English: (x−6)(x+6) / 2499 / квадраты ≥ 0.

## Где «ломается»
1. Пишут (a−b)² вместо (a−b)(a+b).
2. Пытаются разложить a²+b².
3. Не применяют для счёта.
