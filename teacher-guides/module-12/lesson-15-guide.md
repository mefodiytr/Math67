# Методичка к уроку 12.15 — «Квадратное уравнение»

## Цели
1. Через факторизацию.
2. Через √.
3. Виет (упоминание).

## Решения
**Core:** ±3 / ±5 / ±2 / ±1.
**Strong:** 2,3 / −3,−4 / 3,−2 / 0,2.
**Advanced:** −1,−3 / 3 (один).
**Sphinx:** 7.

## English: ±4 / 1,3 / ±3.

## Где «ломается»
1. Забывают **±**.
2. Не приравнивают каждый **множитель** к 0.
3. Считают двойной корень за два разных.

## Дневник
```
Урок 12.15
Корни:                                [1 2 3 4 5]
Факторизация:                         [1 2 3 4 5]
```
