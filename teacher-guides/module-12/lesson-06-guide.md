# Методичка к уроку 12.6 — «Квадрат суммы»

## Цели
1. (a±b)².
2. Геометрия.
3. Применение.

## Решения
**Core:** x²+4x+4 / x²−6x+9 / a²+2ab+b² / 4x²+4x+1.
**Strong:** x²−10x+25 / 9x²+12x+4 / a²−4ab+4b² / 4xy.
**Advanced:** 2x²+2 / 13.
**Sphinx:** 14.

## English: x²−8x+16 / 10404 / 4x.

## Где «ломается»
1. (a+b)² = a²+b² — главная ошибка.
2. Знак среднего члена в (a−b)².
3. Не видят формулы в задаче.
