# Методичка к уроку 12.1 — «Язык»

## Цели
1. Алгебра = арифметика + переменные.
2. Перевод слово ↔ формула.
3. Общий случай.

## Решения
**Core:** 2y+3 / 4x−1 / a+b+c / xy².
**Strong:** x+1 / 3t+5r / 2(a+b), ab / (a+b+c)/3.
**Advanced:** nk + n(n−1)/2 / 4an.
**Sphinx:** xa + yx(x−1)/2.

## English: 2y+3 / words / 2(a+b).

## Где «ломается»
1. Не используют скобки.
2. Путают «больше на» и «больше в».
3. Боятся переменных.

## Дневник
```
Урок 12.1
Слова → формула:                      [1 2 3 4 5]
Формула → слова:                      [1 2 3 4 5]
Скобки:                               [1 2 3 4 5]
```
