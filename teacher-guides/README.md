# teacher-guides/ — методички для учителя

Каждая методичка — **парный файл** к уроку. Один урок = одна методичка.

## Что в методичке

| Раздел | Что внутри |
|--------|-----------|
| **Цели урока** | диагностические маркеры (что должна показать ученица) |
| **Тайминг 90 минут** | таблица: что и сколько минут |
| **Что наблюдать** | поведенческие маркеры, диагностические шкалы |
| **Где «ломается» ребёнок** | типичные ошибки и подвохи |
| **Альтернативные объяснения** | если основной метод «не идёт» |
| **Подробные решения** | разбор всех задач урока |
| **English разбор** | эталонные ответы, методические замечания |
| **Идеи для расширения** | если ребёнок справился быстрее |
| **Идеи для упрощения** | если тема «не идёт» |
| **Дневник учителя** | шкалы 1–5 для записи после урока |

- Каждая методичка ссылается на парный конспект урока в первой же строке.

## Дневник учителя

В конце каждой методички есть шаблон дневника:

```
Урок X.Y
Параметр 1:                    [1 2 3 4 5]
Параметр 2:                    [1 2 3 4 5]
...
Главное наблюдение: ____________________________
```

После каждого урока учитель **обводит** соответствующую цифру для каждого параметра. После финального урока модуля заполняется **карта модуля** — сводная таблица.

## Финальные методички модулей

В каждом модуле есть **финальная методичка** (последний урок), где:
- сводный экзамен по всему модулю;
- английский 4-step Cambridge task;
- церемония Лунного Камня;
- обновление карты навыков ученицы.
