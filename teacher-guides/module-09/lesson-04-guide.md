# Методичка к уроку 9.4 — «Частотные таблицы»

## Цели
1. Чтение таблицы частот.
2. Среднее по таблице (Σx·f / Σf).
3. Группированные данные через середины интервалов.

## Решения
**Core:** 14 / 2 / 35 / 5.83.
**Strong:** 4.1 / 2 / таблица / медиана 4.
**Advanced:** 17.5 / сместится.
**Sphinx:** 5.8 / 5 / 6.

## English: формула / самое частое / много данных.

## Где «ломается»
1. Забывают **умножить** на частоту.
2. Делят на **число строк**, а не на **сумму частот**.
3. В группированных — берут **края** вместо **середин**.

## Дневник
```
Урок 9.4
Частотная таблица:                    [1 2 3 4 5]
Среднее по таблице:                   [1 2 3 4 5]
Группировка:                          [1 2 3 4 5]
```
