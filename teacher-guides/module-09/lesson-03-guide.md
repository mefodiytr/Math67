# Методичка к уроку 9.3 — «Размах»

## Цели
1. Размах = max − min.
2. Сравнение наборов по среднему + размаху.
3. Что значит «однородный».

## Решения
**Core:** 8 / 0 / 11 / 99.
**Strong:** B однороднее / все равны / 1 / Москва.
**Advanced:** 15 / класс A.
**Sphinx:** 5.25 / 5.5 / нет / 9.

## English: 12 / все 6 / A.

## Где «ломается»
1. **min − max** вместо max − min.
2. **Размах = 0** не понимают как «все равны».
3. Не используют размах при **сравнении** наборов.

## Дневник
```
Урок 9.3
Размах:                               [1 2 3 4 5]
Сравнение наборов:                    [1 2 3 4 5]
```
