# Методичка к уроку 9.9 — «Дерево вероятностей»

## Цели
1. Построение дерева.
2. Умножение вдоль пути, сложение между путями.
3. С возвратом vs без возврата.

## Решения
**Core:** 4 / 1/4 / 1/4 / 3/4.
**Strong:** 1/36 / 1/8 / 4/25 / 2/15.
**Advanced:** 0.62 / ≈0.129.
**Sphinx:** 5/14.

## English: 1/8 / 2/15 / понимание.

## Где «ломается»
1. **Складывают** вдоль пути вместо умножения.
2. Не **меняют** вероятность для «без возврата».
3. Не доводят дерево до **листьев**.

## Дневник
```
Урок 9.9
Дерево исходов:                       [1 2 3 4 5]
Умножение вдоль пути:                 [1 2 3 4 5]
Без возврата:                         [1 2 3 4 5]
```
