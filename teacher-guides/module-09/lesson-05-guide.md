# Методичка к уроку 9.5 — «Диаграммы»

## Цели
1. Виды: bar / pie / line / histogram / scatter.
2. Чтение: оси, шкала, тренд.
3. Корректные / некорректные выводы.

## Решения
**Core:** 75% / B / max−min / да.
**Strong:** среднее / 10% / 16 / только репрезентативно.
**Advanced:** 6, 7, 7 / 30 см.
**Sphinx:** 60/30/18/12.

## English: 20% / линейный / самый высокий.

## Где «ломается»
1. Не смотрят на **шкалу** (от 0 ли).
2. Делают вывод по **одной точке**.
3. Путают **bar** и **histogram**.
