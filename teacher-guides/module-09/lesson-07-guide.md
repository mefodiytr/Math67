# Методичка к уроку 9.7 — «Вероятность»

## Цели
1. Формула благ./всех.
2. Свойства 0 ≤ P ≤ 1.
3. Запись %, дробью, десятичной.

## Решения
**Core:** 1/2 / 1/3 / 1/2 / 5/8.
**Strong:** 1/4 / 1/2 / 2/3 / 0.3.
**Advanced:** 3/5 / 1/4.
**Sphinx:** 36 / 1/6.

## English: 2/5 / 2/5 / 0.

## Где «ломается»
1. Не упорядочивают **благоприятные** перед **общими**.
2. Считают, что P > 1 возможно.
3. Забывают про **равновероятность** исходов.

```

Формула вероятности:                  [1 2 3 4 5]
Свойства:                             [1 2 3 4 5]
Простые задачи:                       [1 2 3 4 5]
```
