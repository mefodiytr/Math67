# Методичка к уроку 9.8 — «Сумма вероятностей»

## Цели
1. Σ P = 1.
2. P(не A) = 1 − P(A).
3. Когда удобнее через противоположное.

## Решения
**Core:** 0.6 / 30% / 5/12 / 1.
**Strong:** 5/6 / 3/4 / 3/5 / невозможное и достоверное.
**Advanced:** 1/2 / 7/10.
**Sphinx:** 3/4.

## English: 0.4 / 5/6 / 3/4.

## Где «ломается»
1. Не **сводят** к противоположному.
2. Думают, что P(A) + P(B) = 1 для **любых** A, B.
3. Пытаются считать **«хотя бы один»** напрямую.

## Дневник
```
Урок 9.8
Сумма = 1:                            [1 2 3 4 5]
Противоположное:                      [1 2 3 4 5]
Хотя бы один:                         [1 2 3 4 5]
```
