# Методичка к уроку 9.11 — «Честная игра»

## Цели
1. Честность через равные шансы / E = 0.
2. Расчёт ожидания.
3. Анализ казино / лотерей.

## Решения
**Core:** да / E=1/6 / нет / выгоднее с большим E.
**Strong:** да / E=0 / E=0 / E=2/3.
**Advanced:** E=0 (честная) / E=0 (безразлично).
**Sphinx:** K = 7.

## English: да / E=0 / преимущество дома.

## Где «ломается»
1. Считают **только шансы**, не учитывая **ставки**.
2. Не понимают **отрицательное** ожидание.
3. Думают, что лотерея «обычно» выгодна.
