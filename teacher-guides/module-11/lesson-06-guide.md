# Методичка к уроку 11.6 — «Делимость»

## Цели
1. Вынесение общего множителя.
2. Запись «n, n+1...».
3. n³−n.

## Решения
**Core:** контрпример / 5(n+2) / 6 / 4k².
**Strong:** 2 последовательных / на 8 / 6 / 12.
**Advanced:** 99a + 9b + (a+b+c) / 9·11..1.
**Sphinx:** делится на 24.

## English: 3(n+1) / n(n−1) / 5(n+2).

## Где «ломается»
1. Не разлагают на **общий** множитель.
2. Не записывают **последовательные** через переменную.
3. Считают примеры, а не общий случай.

## Дневник
```
Урок 11.6
Делимость:                            [1 2 3 4 5]
Вынесение множителя:                  [1 2 3 4 5]
Запись через k:                       [1 2 3 4 5]
```
