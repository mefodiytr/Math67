# Методичка к уроку 11.7 — «Чётность»

## Цели
1. Правила +, × для Ч/Н.
2. Доказательства через 2k и 2k+1.
3. n² и n — одной чётности.

## Решения
**Core:** Ч / Ч / Н / Ч.
**Strong:** доказательства.
**Advanced:** n(n+1) / нет.
**Sphinx:** да, чередование.

## English: Ч / док-во / Н.

## Где «ломается»
1. Не записывают n=2k или n=2k+1.
2. Не используют **готовые правила**.
3. Не понимают «**одной чётности**».

