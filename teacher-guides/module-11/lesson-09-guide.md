# Методичка к уроку 11.9 — «От противного»

## Цели
1. Алгоритм метода.
2. Иррациональность √2.
3. Бесконечность простых.

## Решения
**Core:** Эвклид / a=b=0 / max+1 / середина.
**Strong:** док-ва.
**Advanced:** уточнение / противоречие чётности.
**Sphinx:** через остатки ÷3.

## English: 3 классических.

## Где «ломается»
1. Не **формулируют** ¬P.
2. Не выводят **противоречие**.
3. Принимают «не нашёл» за «не существует».
