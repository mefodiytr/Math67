# Методичка к уроку 11.3 — «Контрпример»

## Цели
1. Один контрпример — достаточен.
2. Граничные случаи: 0, 1, отрицательные, дроби.
3. Исключения.

## Решения
**Core:** 3² / 2,3,5 / n=0,1 / любой неравный.
**Strong:** 6 / отрицательные / 2+3 / большой прямоугольник.
**Advanced:** 9 / n=40.
**Sphinx:** n=0.5.

## English: 2 / отриц / достаточно одного.

## Где «ломается»
1. Считают, что нужно **много** контрпримеров.
2. Не проверяют **0, 1, отрицательные, дроби**.
3. Путают контрпример и пример.

## Дневник
```
Урок 11.3
Контрпример:                          [1 2 3 4 5]
Граничные случаи:                     [1 2 3 4 5]
Исключения:                           [1 2 3 4 5]
```
