# Методичка к уроку 11.4 — «Всегда / иногда / никогда»

## Цели
1. 3 ответа.
2. Justify.
3. Cambridge формат.

## Решения
**Core:** всегда / никогда / всегда / иногда.
**Strong:** всегда / всегда / всегда / иногда.
**Advanced:** иногда / иногда.
**Sphinx:** всегда (через чётность a², b²).

## English: всегда / иногда / всегда.

## Где «ломается»
1. Отвечают «иногда» **без обоснования** обоих случаев.
2. Не приводят **контрпример** для «иногда».
3. Не понимают «никогда» как доказательство **отсутствия**.

## Дневник
```
Урок 11.4
Всегда / иногда / никогда:            [1 2 3 4 5]
Justify:                              [1 2 3 4 5]
```
