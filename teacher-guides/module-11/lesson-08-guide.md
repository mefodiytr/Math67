# Методичка к уроку 11.8 — «Геометрия»

## Цели
1. Структура: дано / черт. / док-во / вывод.
2. Признаки равенства треугольников.
3. Запись по пунктам.

## Решения
**Core:** нет / Л / да (равносторонний) / Л.
**Strong:** доказательства.
**Advanced:** Вариньон / диагонали ромба.
**Sphinx:** h ≤ c/2 (через AM-GM).

## English: 3 доказательства.

## Где «ломается»
1. Не **обосновывают** каждый шаг.
2. Не используют **точные** признаки СУС/УСУ/ССС.
3. Пропускают **дано**.
