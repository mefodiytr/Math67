# Методичка к уроку 1.3 — «Чайный Домик»

## Цели

1. Уверенное умножение и деление дробей.
2. Привычка **сокращать перед умножением**.
3. Работа со смешанными числами.
4. Понимание «*of* = ×» в английском.

## Что наблюдать

- **сокращает ли** перед умножением (главный признак «культурного» счёта);
- помнит ли превратить смешанные в неправильные **прежде** чем делить;
- видит ли «of» как умножение.

## Где «ломается»

1. **«Деление = деление»**: ребёнок делит числитель на числитель, забывая «перевернуть».
2. **Не сокращает**: считает 7·12 / 3·7 в лоб.
3. **Смешанное при умножении**: умножает «целое × целое + дробное × дробное» — крупная ошибка.
4. **Полквартиры в очках (#15)**: ребёнок не замечает, что 21·1/2 = 10.5, и пишет «10.5 девочек». Хорошая возможность поговорить о **разумности ответа**.

## Подробные решения

### Core
1) 3/8. 2) 10/40 = 1/4. 3) 3/7 · 14/3 = 14/7 = **2**. 4) 5/6 · 3 = 15/6 = 5/2 = **2·1/2**. 5) 24. 6) 60. 7) 3/2 · 2/3 = **1**. 8) 13/4 · 2/3 = 26/12 = **13/6 = 2·1/6**. 9) 4/9. 10) 40/15 = **8/3**.

### Strong
11) 5·4·3 / 8·15·2 = 60/240 = **1/4**.
12) 9/4 · 10/3 = 30/4 = **15/2 = 7·1/2**.
13) 7/9 · 27/14 = (7·27)/(9·14) = 189/126 = **3/2**.
14) x = 25/12 · 6/5 = **5/2 = 2·1/2**.
15) Здесь **диагностика разумности**: 36·7/12 = 21 девочка; 21/2 = 10.5 — некратно. Хорошо, если ребёнок скажет «получилось 10.5, то есть либо 10, либо 11, в условии нужно уточнение». Принимай и 10, и 11 с обоснованием.
16) 2/3 + 1/3 · 1/2 = 2/3 + 1/6 = **5/6**.
17) 13/4 · 12/5 = 156/20 = **39/5 = 7·4/5**.
18) 7/4 · 4/7 = **1 кг**.

### Advanced
19) (11/12) · (1/2) = **11/24**.
20) 7/3 · 10/14 = 5/3 = **1·2/3**.
21) x = 5/8 · 4/3 = **5/6**.
22) Перекрест: 4(2x − 1) = 3(x + 1) → 8x − 4 = 3x + 3 → 5x = 7 → **x = 7/5**.

### Sphinx
**Ответ: 0 литров.** Условие согласовано: 1 л = 0.4 (первая чашка) + 0.6 (вторая чашка). Главное — внимательно прочитать.

## English разбор

**(a) 13/5 ÷ 5/4 = 13/5 · 4/5 = 52/25 = 2·2/25.**
**(b) 480 · 1/4 = 120 мл.** Конструкция «Lena drinks 3/4 of …» = «×3/4 от объёма».

## Расширение / упрощение

- **Расширение:** «волшебная цепочка» — задача с 4 действиями, без скобок: *(2/3) · (3/4) · (4/5) · (5/6) = 1/3* (телескопическое сокращение).
- **Упрощение:** Strong до 11–14, без концентраций.
