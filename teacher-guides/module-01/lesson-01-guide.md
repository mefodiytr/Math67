# Методичка к уроку 1.1 — «Возвращение в Сад. Карта Дробей»

> К уроку: `lessons/module-01/lesson-01-vozvraschenie.md`

## Цели

1. Освежить **понятия** числителя/знаменателя.
2. Закрепить **сокращение** через НОД.
3. Закрепить **сравнение** дробей.
4. Подготовить базу к 4 действиям с дробями.

## Что наблюдать

- ребёнок понимает **смысл** дроби, не только записывает «черту»?
- какой метод сравнения предпочитает?
- видит ли несократимость с первого взгляда?
- умеет ли работать со смешанными числами?

## Где «ломается»

1. **Сравнение с разными знаменателями.** Дети сравнивают «по числителю», игнорируя знаменатель.
2. **Сокращение.** Сокращают только на 2 или 3, не доводя до НОД.
3. **Смешанное → неправильная.** Забывают добавить знаменатель в формулу: *2·3/7 = (2·7+3)/7 = 17/7*.
4. **Дроби, равные 1.** Дети не видят, что *7/7 = 1*. Это критично для будущего.

## Подробные решения

### Core
1) 3/8.
2) 4/12 = 1/3 (НОД 4); 9/15 = 3/5 (НОД 3); 14/21 = 2/3 (НОД 7); 25/40 = 5/8 (НОД 5).
3) 11/4 = 2·3/4; 17/5 = 3·2/5; 23/6 = 3·5/6.
4) 17/7; 37/9; 17/3.
5) 4/7. 6) 5/8 (больший знаменатель → меньшая доля при равном числителе).
7) Любые: 2/6, 3/9, 4/12.
8) 1/12.

### Strong
9) К 24: 14/24 vs 15/24 → 5/8 больше.
10) 60/144 = 5/12 (НОД 12).
11) К 120: 80, 75, 70, 88. Порядок: 7/12 < 5/8 < 2/3 < 11/15.
12) 3/8 = 6/16; 6/16 − 5/16 = 1/16. Лена больше.
13) 5/12 (или 7/16, 9/24, …).
14) 60·2/5 = 24, 60·1/4 = 15, остаток 21.
15) 30/90 = 1/3.

### Advanced
16) 7÷15: остатки 7, 70/15=4 ост 10, 100/15=6 ост 10 — период 6 → 0.4(6).
17) k/12 < 7/8 ⇒ 8k < 84 ⇒ k < 10.5 ⇒ k = 10.
18) 7/24.
19) Сравни 13/29 ≈ 0.448 — наименьшая.

### Sphinx
**1/2 + 1/3 + 1/6 = 1**, **1/3 + 1/4 + 5/12 = 1**, **1/2 + 1/5 + 3/10 = 1**, **1/2 + 1/4 + 1/4** — повтор. Принимать **любые 3 разных** набора с попарно разными знаменателями.

## English разбор

**(a) 28/42.** НОД(28, 42) = 14. → **2/3**.
**(b) 3/4 → знаменатель 28.** Умножь оба члена на 7: **21/28**.

Если ребёнок сразу пишет 2/3 — отлично, у него «глаз». Если идёт через шаг (28:14, 42:14) — тоже нормально.

## Расширение / упрощение

- **Расширение:** найди дроби с одинаковым НОДом числителя и знаменателя; докажи, что сократимая дробь *na/nb* всегда сократима.
- **Упрощение:** до Strong задач 9–12.
