# Методичка к уроку 5.2 — «Близнецы. Симметрия»

## Цели

1. 3 типа симметрии для точек.
2. Симметрия фигур.
3. Середина отрезка.

## Что наблюдать

- разделяет ли Ox / Oy / O;
- использует ли формулу середины;
- видит ли «диагонали параллелограмма».

## Где «ломается»

1. **Симметрия отн. O** — путают с осями.
2. **Середина** — забывают делить на 2.
3. **Параллелограмм через диагонали** — нужен метод.

## Подробные решения

### Core
1) (2,−7). 2) (4,3). 3) (−5,2). 4) (0,−6). 5) (3,0). 6) I/IV. 7) II/IV.

### Strong
8–14) См. урок.

### Advanced
15) ✓. 16) (5,5). 17) Формула. 18) (0, 5).

### Sphinx
**D(−3, 6).**

## English разбор

**(a) (2,5), (−2,−5), (−2,5). (b) (4,7). (c) (3, 5).**

## Расширение / упрощение

- **Расширение:** симметрия отн. произвольной точки.
- **Упрощение:** Strong до №13.
