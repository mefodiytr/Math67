# Методичка к уроку 3.1 — «Зал Переменной»

## Цели

1. Понятия переменной, выражения, значения выражения.
2. Запись выражения по словесному описанию.
3. Подготовка к раскрытию скобок.

## Что наблюдать

- видит ли разницу выражение / уравнение;
- подставляет ли отрицательное аккуратно (со скобками);
- умеет ли составлять выражение по тексту.

## Где «ломается»

1. **Подстановка отрицательного:** *2x + 5* при *x = −3*: пишут *2·−3 = −6, +5 = −1* без скобок и часто ошибаются. Учим *2·(−3) = −6*.
2. **Степень с минусом:** *(−2)² = 4*, не *−4*.
3. **«Удвоенный *x*»** = 2x, не x².

## Расширение / упрощение

- **Расширение:** обсудить «формула — это выражение, которому **дали имя**».
- **Упрощение:** Strong до №13–17, без 19, 20.
