## Где «ломается» в финале

1. **№15 (11² − 9² без подстановки):** дети считают «в лоб», не используют разность квадратов.
2. **№18:** связь с Модулем 1 — двойная скидка p% с результатом 162. Видит ли *(1 − p/100)²*?
3. **Sphinx (a² + b², a³ + b³):** требует знания формул и подстановки.
4. **English (d):** *n² + 3n + 2 = (n+1)(n+2)* — требует факторизации квадратного.

## Подробные решения

### Часть I
1) 19. 2) 16. 3) 2x+7. 4) Да. 5) 5x−7.

### Часть II
6) 4x−7.
7) 7.
8) 8a⁵ (если идти через 2³·a⁶·a⁻¹).
9) 4x²+12x+9.
10) a²−16.

### Часть III
11) x³−1.
12) (3x−5)(3x+5).
13) 2(x−3)(x+3).
14) 3(a²−2a+4).
15) 40.

### Часть IV
16) ✓.
17) aₙ=4n+1; a₁₀₀=401.
18) p=10%.

### Sphinx
а) 20. б) 72. в) (a−b)² = 4, |a−b| = 2.

### English Final
(a) 4x. (b) 4x(x−3)(x+3). (c) n=4. (d) (n+1)(n+2). ✓

## Идеи для расширения

- Найти *a⁴ + b⁴* при *a + b = 6, ab = 8* (через *(a² + b²)² − 2(ab)² = 400 − 128 = 272*).
- Пифагоровы тройки: *3² + 4² = 5²*.

## Идеи для упрощения

- Часть III до №13.
- Sphinx — только пункт (а).
- English — (a) и (b), (c)/(d) — на дом.
