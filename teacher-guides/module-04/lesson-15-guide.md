# Методичка к уроку 4.15 — «Зал Параметра»

## Цели

1. Понятие параметра.
2. Три случая: единственное / нет / бесконечно.
3. Подготовка к 8 классу (квадратные).

## Что наблюдать

- разделяет ли случаи по значению параметра;
- видит ли «нет решений» при коэффициенте 0;
- решает ли «найди *a*, чтобы *x = ...*».

## Где «ломается»

1. **«Параметр = ученик»** — путают с переменной.
2. **«0·x = 0 → нет решения»** — нет, бесконечно.
3. **«0·x = 6 → x = 0»** — нет, нет решений.

## Подробные решения

### Core
1) 4. 2) 2. 3) 2. 4) 2. 5) 4.

### Strong
6) При k≠3: x=12/(k−3); при k=3: нет.
7) x = −p/4.
8) m = 4.
9) a = 7.
10) При a=1: x=3; при x=3: a=1.
11) x = b/3.
12) Все три случая.
13) При p≠1: x=2; при p=1: любой.
14) (k−5)x = −2; при k=5: нет.

### Advanced
15) При m≠−2: x=1; при m=−2: любой.
16) 2 / 1 / 0.
17) a = 1/2.
18) При p≠1.

### Sphinx
**k ∈ {3, 4, 5, 8}.**

## English разбор

**(a) m ≠ 5: x = 10/(m−5); m = 5: нет. (b) k = 4. (c) a = 1.**

## Расширение / упрощение

- **Расширение:** «когда квадратное имеет корни» — будет в 8 классе.
- **Упрощение:** Strong до №12, без №13, 14.
