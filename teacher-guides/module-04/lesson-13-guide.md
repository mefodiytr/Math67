# Методичка к уроку 4.13 — «Зал Знака»

## Цели

1. Понятие неравенства.
2. Свойства неравенств.
3. Главная ловушка: умножение на отрицательное.

## Что наблюдать

- замечает ли смену знака при умножении на «−»;
- решает ли двойные неравенства правильно;
- работает ли с «целыми решениями».

## Где «ломается»

1. **Умножение на отрицательное без переворота знака**.
2. **«−x > 5 → x > −5»** — не переворачивают знак.
3. **Двойное неравенство**: преобразуют только одну часть.

## Подробные решения

### Core
1) И. 2) И. 3) Л. 4) И. 5) Л. 6) x<7. 7) x>11. 8) x>5. 9) x≤5. 10) x<−5.

### Strong
11) x≥4. 12) x>−3. 13) x>−5. 14) x≤3. 15) x>4. 16) x≥−3. 17) x<−3. 18) x≥3. 19) x≤3. 20) **4**.

### Advanced
21) x>11. 22) x≤3.5. 23) x<5. 24) {2,3,4,5,6}.

### Sphinx
**x ≤ −3, наибольшее −3.**

## English разбор

**(a) x > 2. (b) x ≥ −4. (c) {−2, −1, 0, 1, 2, 3, 4}.**

## Расширение / упрощение

- **Расширение:** числовая прямая для неравенств — Урок 4.14.
- **Упрощение:** Strong до №18.
