# Методичка к уроку 4.1 — «Большой Зал Весов»

## Цели

1. Понятие уравнения и корня.
2. Простейшие линейные уравнения.
3. Проверка подстановкой.

## Что наблюдать

- проверяет ли корень подстановкой;
- видит ли разницу уравнение / тождество;
- уверенно ли работает с переносом.

## Где «ломается»

1. **Перенос без смены знака**: *x + 7 = 15* → *x = 15 + 7 = 22*. Самая ошибка.
2. **«Уравнение всегда имеет один корень»** — нет, *x² = 16* имеет два.
3. **Деление на коэффициент**: *3x = 21* → *x = 21·3 = 63* (вместо деления).

## English разбор

## Расширение / упрощение

- **Расширение:** обсудить «уравнение без корней» (5x = 5x + 1 → 0 = 1).
- **Упрощение:** Strong до №14, без №19, 20.
