# Методичка к уроку 2.11 — «Доказательства делимости»

## Цели

1. Структура доказательства.
2. Доказательство через разложение и через остатки.
3. Контрпример.
4. Подготовка к Модулю 11 (доказательства).

## Что наблюдать

- использует ли структуру «дано / доказать / решение»;
- доказывает ли через **общий случай**, а не через примеры;
- знает ли разницу «опровергнуть = контрпример».

## Где «ломается»

1. **«Проверил несколько примеров — доказал»** — главное непонимание.
2. **«Контрпример = другой случай»** — путают с обобщением.
3. **От противного** — большая нагрузка для 6 класса; брать как **необязательное** в задаче №12.

## Подробные решения

### Core
1) ✓ через n(n+1).
2) ✓ через (2k+1)(2m+1).
3) **Опровергнуть** (сумма двух нечётных чётна).
4) ✓ через 5(n+2).
5) ✓ через (2k+1)².
6) ✓ через 3(2n+3).

### Strong
7) 4(n+3−2m).
8) 2n+1.
9) Через n³−n + 6n.
10) Не опровергается (всегда нечётно). Принимай ответ «утверждение верно».
11) ≡ 2 mod 3.
12) Доказательство Евклида.
13) ✓ через n²−1=(n−1)(n+1).

### Advanced
14) ✓ через (p−1)(p+1).
15) 2(5n−3m+1).
16) ✓ от противного.
17) p = 11 → 2047 = 23·89.

### Sphinx
**Квадраты mod 8 ∈ {0, 1, 4}. Суммы трёх ∈ {0, 1, 2, 3, 4, 5, 6}. 7 невозможен.** ✓

## English разбор

**(a) 4n+6 = 2(2n+3) — чётно. ✓**
**(b) 4n(n+1) — n(n+1) чётно → 8|.** ✓
**(c) n=40: 1681 = 41².** ✓

## Расширение / упрощение

- **Расширение:** простое доказательство бесконечности простых (Евклид).
- **Упрощение:** Strong до №7, 8, 13, без №12.
