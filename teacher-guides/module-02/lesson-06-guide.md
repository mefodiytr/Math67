# Методичка к уроку 2.6 — «Камень НОК»

## Цели

1. НОК через факторизацию (максимальные степени).
2. Формула *НОД·НОК = a·b*.
3. Применение НОК (циклы, шестерни, лампочки).

## Что наблюдать

- использует ли формулу для проверки;
- видит ли НОК как «общая обёртка»;
- решает ли задачи на циклы.

## Где «ломается»

1. **НОК = меньшее** (путают с НОД).
2. **Берут НОД степеней** при факторизации.
3. **Циклические задачи**: путают «через сколько» и «сколько раз».

## Расширение / упрощение

- **Расширение:** НОК трёх и более чисел через **НОК(НОК(a, b), c)** — последовательно.
- **Упрощение:** Strong до 11–14, без задачи с шестернями.
