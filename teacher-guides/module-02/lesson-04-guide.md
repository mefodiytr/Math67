# Методичка к уроку 2.4 — «Дерево Факторизации»

## Цели

1. Свободная факторизация чисел.
2. Запись в степенной форме (index form).
3. Применение для подсчёта делителей.
4. «Полный квадрат через факторизацию» (Cambridge classic).

## Что наблюдать

- идёт ли по простым **в порядке** 2, 3, 5, 7, …;
- использует ли индексную форму;
- понимает ли «полный квадрат — все степени чётные».

## Где «ломается»

1. **Пропуск простого**: «360 = 2³·3·5» (забыли вторую 3).
2. **Сложение вместо умножения** при подсчёте делителей.
3. **Полный квадрат**: умножают на **минимум 1**, забывая про **третью степень в разложении**.

## Подробные решения

### Core
1) 2·3². 2) 2·5². 3) 2²·3·7. 4) 2²·5². 5) 2⁴·3². 6) 3²·5². 7) 2²·7². 8) 2³·5³. 9) 120. 10) 100.

### Strong
11) 24. 12) 16. 13) 24 (или 30, требует перебора). 14) 30. 15) 132. 16) 16. 17) 32. 18) 6, 7, 8.

### Advanced
19) Сложная задача — нет натурального k. Принимай обоснование.
20) 168.
21) 96 (12 делителей).
22) ~31 числа (5-гладкие до 1000). Принимай «около 30» с обоснованием.

### Sphinx
**Решений нет в натуральных** — 9b = 3 не даёт целого b. Это диагностическая задача.

## English разбор

**(a) 540 = 2²·3³·5.**
**(b) (2+1)(3+1)(1+1) = 24.**
**(c) Не хватает 3¹·5¹ — умножь на 15.**

## Расширение / упрощение

- **Расширение:** «полный куб через разложение» — все степени должны быть кратны 3.
- **Упрощение:** Strong до №11, 12, 14, 15.
