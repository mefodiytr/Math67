# Методичка к уроку 2.5 — «Камень НОД»

## Цели

1. Два метода нахождения НОД: факторизация + Евклид.
2. Применение НОД (плитки, ленты, упаковки).
3. Связь НОД и сокращения дробей.

## Что наблюдать

- какой метод выбирает (факторизация для маленьких, Евклид для больших);
- понимает ли алгоритм Евклида (последний ненулевой остаток);
- видит ли НОД в реальной задаче «нарезка лент».

## Где «ломается»

1. **Минимальные степени общих**: дети берут максимальные (это НОК).
2. **Евклид**: останавливаются на первом совпадении, а не на нуле.
3. **НОД(0, n) = n**: путают с 0.

## Расширение / упрощение

- **Расширение:** *НОД(a, b) · НОК(a, b) = a · b*. Это связь.
- **Упрощение:** Strong до 11–14, без №15, 16.
