# Методичка к уроку 7.2 — «Поле Прямоугольников»

## Цели
1. S = a·b, P = 2(a+b).
2. Прямые и обратные задачи.
3. Практические задачи.

## Тайминг (90 мин)
Стандартный (как в Модуле 7.1).

## Что наблюдать
- использует ли периметр для нахождения сторон;
- учитывает ли единицы;
- решает ли через систему a+b и ab.

## Где «ломается»
1. **P = a+b** — нет, *2(a+b)*.
2. **Единицы плитки** — забывают перевести.
3. **Окно при покраске** — не вычитают.
