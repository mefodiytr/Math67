# stories/ — сюжетные арки модулей

## Структура арки

| Раздел | Что внутри |
|--------|-----------|
| Завязка | как Лена попадает в локацию модуля |
| Структура по урокам | таблица: урок → локация → помощник → артефакт |
| Скрытая интрига | сквозной мини-сюжет модуля (например, «бакэнэко появляется в полнолуние») |
| Финал арки | церемония Лунного Камня |
| Что говорит учитель | короткие фразы для каждого урока (1 строка) |

## Как использовать

1. Перед началом модуля — прочитать арку **целиком**.
2. В начале каждого урока — зачитать **одну строку** из таблицы «что говорит учитель».
3. На финальном уроке — провести **церемонию Лунного Камня** (зажечь следующую луну на «Печати Адепта» ученицы — рисунок, наклейка, бумажка).

## Сквозной сюжет курса

К концу года Лена соберёт **9 Лунных Камней** (Модули 1–9). Печать Адепта горит всеми девятью лунами. Это — символ **полного освоения программы**.

| Камень | Откуда | Цвет |
|--------|--------|------|
| Дробей | Модуль 1 | чёрный с серебряной жилкой |
| Простых | Модуль 2 | гладкий чёрный с серебряной точкой |
| Знаков | Модуль 3 | сине-зелёный с x и y |
| Весов | Модуль 4 | сапфирово-голубой в форме гири |
| Карты | Модуль 5 | золотой в форме координатной розы |
| Треугольников | Модуль 6 | (готовится) |
| Долины Измерений | Модуль 7 | (готовится) |
| Лабиринта | Модуль 8 | (готовится) |
| Обсерватории | Модуль 9 | (готовится) |
