## Поза по умолчанию (`-base`)

- Нейтральная, в полный рост или поясная.
- Лицом / в три четверти к зрителю.
- **Прозрачный фон** (PNG-32).
- Размер: 1024×1024.
- Освещение: **мягкое сверху**.

## Дополнительные позы (когда понадобятся)

- `<id>-thinking` — задумчивая.
- `<id>-pointing` — указывает на что-то (для объяснения).
- `<id>-victory` — после победы (улыбка, поднятая лапа).
- `<id>-sad` — для эмоциональных моментов.
