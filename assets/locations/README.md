# `assets/locations/` — фоновые локации

## Принципы

- **Сплошной фон** (не прозрачный).
- 1920×1080 (16:9 для слайдов).
- Возможна также версия 2480×3508 (A4 портрет) для обложек глав.
- **Без персонажей** — они подкладываются отдельным слоем.
- **Атмосферное освещение** — легко узнаваемая «душа» места.
