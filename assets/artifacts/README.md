## Принципы

- **Прозрачный фон** (PNG-32).
- **Светящийся** ореол вокруг каждого артефакта.
- **Силуэт лёгко узнаваем** на маленьком размере (256×256).
- **Цветовая идентификация** соответствует модулю (см. `prompts/colour-palette.md`).

## Применение

В сюжете лесcонов артефакты появляются в **финальных** уроках каждого модуля. На эмблеме Лены они **накапливаются** — см. `assets/emblems/`.
