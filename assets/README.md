# assets/ — вспомогательные ресурсы

Папка зарезервирована для вспомогательных ресурсов курса:

- **Сгенерированные иллюстрации** для слайдов (`.png`, `.jpg`, `.webp`).
- **Иконки персонажей** (Цукико, Цинлун, Хэйхи, Манэки и т.д.).
- **Логотипы и знаки** (Печать Адепта, Лунные Камни, флаги).
- **Шаблоны для печати** (карта навыков, дневник учителя, бланки).

## Когда использовать

Если иллюстрация **используется в нескольких уроках** или модулях — кладём сюда. Если иллюстрация **уникальна для одного слайда** — оставляем в .pptx.

## Соглашения по именованию

```
assets/
├── characters/                   ← портреты персонажей
│   ├── tsukiko.png
│   ├── cinglong.png
│   └── ...
├── artifacts/                    ← Лунные Камни и артефакты
│   ├── moon-stone-fractions.png
│   └── ...
├── icons/                        ← иконки уровней (★, ★★, ★★★, ★★★★)
└── templates/                    ← бланки для печати
    └── seal-of-adept.png
```
