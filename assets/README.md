# `assets/` — атомарная библиотека визуальных ресурсов

Здесь живут **переиспользуемые** изображения и промты для них. Один атом = одно изображение, которое **можно подставить** в любой слайд, страницу книги или раздатку.

## Структура

```
assets/
├── prompts/          ← style-prefix, палитра, журнал генерации
├── characters/       ← 13 героев (Лена, Цукико, Сфинкс, ...)
├── artifacts/        ← 12 главных предметов (9 Лунных Камней, Перо, Кристалл, Печать)
├── locations/        ← 13 модульных локаций (фоны без персонажей)
├── emblems/          ← 13 состояний эмблемы Лены (прогресс)
└── ui/               ← иконки, рамки, декор (заполняется позже)
```

## Соглашение: каждый PNG идёт с `.prompt.md`

```
characters/lena/lena-base.png            ← сгенерированное изображение
characters/lena/lena-base.prompt.md      ← промт + параметры генерации
```

**Зачем:** позволяет **перегенерировать** ассет в любой момент с тем же стилем, не вспоминая, «как мы это делали».

## Как использовать атомы

В YAML-манифесте слайда (`slides-yaml/module-NN/lesson-MM.yaml`) ссылаемся по **id**:

```yaml
characters:
  - id: lena
    pose: thinking
artifacts:
  - id: moon-stone-08
location: 08-labyrinth-lanterns
```

Скрипт сборки (`tools/render-slides.ts`) подтянет нужные файлы из `assets/`.

## Pipeline генерации

1. Открыть `*.prompt.md`.
2. Скопировать **финальный промт** в GPT Image / Midjourney.
3. Сохранить результат рядом как `*.png` (или `.webp` для веба).
4. Записать дату и сид в `prompts/generation-log.md`.

## Соглашения по именованию

- **kebab-case**: `lena-thinking.png`, `moon-stone-01-fractions.png`.
- **id-первым**: `08-labyrinth-lanterns.png` — модуль/индекс впереди.
- **Прозрачный фон** для персонажей и артефактов (PNG-32).
- **Сплошной фон** для локаций и эмблем.

## Размеры

| Тип | Разрешение | Формат |
|---|---|---|
| Персонажи | 1024×1024, прозрачный | PNG |
| Артефакты | 1024×1024, прозрачный | PNG |
| Локации | 1920×1080, со фоном | PNG/JPG |
| Эмблемы | 1024×1024, прозрачный | PNG |
| Иконки UI | 256×256 | PNG/SVG |
