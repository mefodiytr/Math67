# `assets/ui/` — иконки, рамки, декор

Заполняется по мере необходимости. Здесь живут **мелкие** ресурсы:

```
ui/
├── icons/
│   ├── stars/           ← ★, ★★, ★★★, ★★★★ (для уровней)
│   ├── modules/         ← квадратные иконки модулей 0..12 (256×256)
│   └── tools/           ← пиктограммы (формула, чертёж, эксперимент)
├── decorations/
│   ├── frames/          ← рамки для слайдов
│   ├── dividers/        ← разделители (сакура, волны, инь-ян)
│   └── corners/         ← угловые украшения
└── progress-bar/
    └── nine-moons-bar/  ← 9-сегментный прогресс
```

## Принципы

- **SVG предпочтителен** (масштабируется без потерь).
- Если PNG — 256×256 (иконки) или 512×128 (баннеры).
- Прозрачный фон.
- Минималистичный sumi-e силуэт.
