# modules/ — описания модулей курса

Каждый файл здесь — **программа одного из 13 модулей** курса. Это «макроуровень»: что учим, какие уровни, типовые задачи, контроль, результат.

> Параллельно с модулем можно открыть [сюжетную арку](../stories/) и [папку с уроками](../lessons/).

## Что внутри каждого файла

- длительность модуля (недель / занятий);
- цель модуля;
- темы по 4 уровням сложности (Core / Strong / Advanced / Olympiad);
- типовые задачи;
- Cambridge-блок (английская терминология);
- распространённые ошибки;
- связи с другими модулями;
- формат контроля и домашка;
- ожидаемый результат после модуля.
