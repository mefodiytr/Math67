# Урок 3.13 — n-й член последовательности

> Длительность: 90 минут.
> Куратор: Бакэнэко. Локация: 7 этаж Башни.

---

## Сюжет

Бакэнэко с двумя хвостами сидит на каменной скамье на верхнем этаже. Перед ней — лента с чередой цифр.

— *Каждое число — это **жизнь**. У ленты есть **формула**, которая даёт **n-ю** жизнь. Найди её.*

---

## Что узнаем сегодня

- что такое последовательность;
- понятие *n*-го члена;
- арифметическая прогрессия (вводно);
- задачи на поиск формулы.

---

## Объяснение

**Последовательность** — упорядоченный набор чисел. Каждое — **член**.
*Пример:* 5, 8, 11, 14, 17, … (по 3).

**n-й член** — формула, которая даёт *n*-ю позицию.
- Если последовательность: *5, 8, 11, 14, …* (разница *d = 3*),
- Тогда формула: *aₙ = 3n + 2*.

**Алгоритм поиска формулы (для линейного увеличения).**
1. Найди разницу между соседями (*d*).
2. Формула: *aₙ = d·n + (a₁ − d)*.

> Пример: *5, 8, 11, …*: *d = 3*, *a₁ − d = 5 − 3 = 2*. → *aₙ = 3n + 2*. ✓

---

## Пример

Найди формулу *n*-го члена и вычисли *a₂₀* для:
*4, 7, 10, 13, 16, …*

- Разница *d = 3*.
- *a₁ = 4. a₁ − d = 1.*
- *aₙ = 3n + 1.*
- *a₂₀ = 3·20 + 1 = 61.*

---

## Core ★

Найди разницу и **формулу n-го члена**:
1. *2, 5, 8, 11, …*
2. *7, 9, 11, 13, …*
3. *3, 8, 13, 18, …*
4. *10, 8, 6, 4, …* *(Подсказка: разница отрицательная.)*
5. *1, 4, 7, 10, …*

Найди *a₁₀*:
6. *aₙ = 2n + 5.*
7. *aₙ = 5n − 3.*
8. *aₙ = 100 − 3n.*

Узнай номер члена:
9. В последовательности *3, 7, 11, 15, …* — какой номер у члена 47?
10. В *aₙ = 4n + 1* — какой номер у члена 81?

## Strong ★★

11. Найди формулу *n*-го члена для квадратной последовательности: *1, 4, 9, 16, 25, …* *(Подсказка: квадраты.)*
12. Найди формулу для *2, 6, 12, 20, 30, …* *(Подсказка: *aₙ = n(n + 1)*.)*
13. Найди формулу для *1, 3, 6, 10, 15, …* *(Треугольные числа: *aₙ = n(n + 1)/2*.)*
14. Найди *a₁₀₀* в *aₙ = 3n − 2*.
15. Сколько членов последовательности *5, 9, 13, …, 105*?
16. Найди формулу для *5, 10, 17, 26, 37, …* *(Подсказка: *aₙ = n² + 4*.)*
17. Лена выкладывает камешки в виде квадратов: 1×1, 2×2, 3×3. Сколько камешков на 10-м шаге?
18. Найди формулу для *10, 7, 4, 1, −2, …* *(Разница −3.)*
19. Сумма первых *n* нечётных чисел = *n²*. Проверь: 1, 1+3, 1+3+5, …
20. *aₙ = (−1)ⁿ · n*. Запиши первые 5 членов.

---

## Advanced ★★★

21. Найди формулу для *2, 5, 10, 17, 26, …* *(Подсказка: разности 3, 5, 7, 9 — нечётные.)*
22. Найди *n*-й член последовательности *1, 1, 2, 3, 5, 8, 13, …* *(Это знаменитая последовательность.)*
23. Сколько чисел между 100 и 999, делящихся на 7? *(Это арифметическая прогрессия.)*
24. *aₙ = 2n − 1*. Найди сумму первых 100 членов. *(Подсказка: формула суммы.)*

---

## ★★★★ Sphinx Challenge

25. **Лента Бакэнэко.**
*aₙ = n³ − n.* Найди *a₁, a₂, a₃, a₄, a₅*.
А потом докажи: *aₙ* делится на 6 при любом натуральном *n*.

*(Подсказка: *n³ − n = n(n − 1)(n + 1)*.)*

---

## English with the Bell Fairy 🔔

**Vocabulary**
- *sequence, term, nth term, position-to-term rule*
- *arithmetic progression, common difference*

**Task.**
> *(a) The nth term of a sequence is 4n − 3. Write the first 4 terms.*
> *(b) Find the nth term of the sequence: 6, 11, 16, 21, ...*
> *(c) The nth term is n² + 1. Find the term number whose value is 50.*

> [Перевод для учителя.]
> «(a) Найди первые 4 члена aₙ = 4n − 3.
> (b) Найди формулу для 6, 11, 16, 21, ...
> (c) При aₙ = n² + 1, найди номер n с aₙ = 50.»

> **Методическая заметка.**
> (a) 1, 5, 9, 13.
> (b) 5n + 1.
> (c) n² + 1 = 50 → n² = 49 → **n = 7**.

---

## Кошачий факт 🐾

В **Японии** считается: «**Кот должен прожить 9 жизней**, и каждая на **1 год дольше** предыдущей». Если первая жизнь — 5 лет, то 2-я — 6, 3-я — 7, …, 9-я — 13. Сумма: *(5 + 13) · 9 / 2 = 81 год*. **9-й член** этой последовательности — 13.
