# Урок 3.11 — Тождества и доказательства

> Длительность: 90 минут.
> Куратор: Цинлун. Локация: 6 этаж Башни.

---

## Сюжет

Цинлун стоит у **Зеркала Истины**. В нём отражаются равенства.

— *Тождество — это **истинное всегда** равенство. Уравнение — **иногда**.*

---

## Что узнаем сегодня

- что такое тождество;
- разница тождество / уравнение;
- доказательство тождеств преобразованиями;
- проверка тождества подстановкой.

---

## Объяснение

**Тождество** — равенство, **истинное при любом значении** переменной.
*Например:* *(a + b)² ≡ a² + 2ab + b²*.

**Уравнение** — равенство, истинное **при некоторых** значениях.
*Например:* *2x − 3 = 7* (только при *x = 5*).

**Знак «≡»** означает «тождественно равно». В школе часто пишется обычным «=».

**Как доказать тождество.**
1. Преобразовать **левую** часть, чтобы получилась **правая**.
2. Или преобразовать **правую**, чтобы получилась **левая**.
3. Или преобразовать **обе** части к одному виду.

**Как опровергнуть.** Найти **одно** значение переменной, при котором левая ≠ правая.

---

## Пример

**Докажи тождество:** *(a + b)² − (a − b)² = 4ab*.

**Преобразуем левую часть.**
- *(a + b)² = a² + 2ab + b²*.
- *(a − b)² = a² − 2ab + b²*.
- Разность: *(a² + 2ab + b²) − (a² − 2ab + b²) = 4ab*. ✓

**Q.E.D.**

---

## Core ★

Истинно ли тождество? Если да — докажи; если нет — опровергни.
1. *3(x + 2) = 3x + 6*.
2. *(a + b)(a − b) = a² + b²*.
3. *a² + b² = (a + b)²*.
4. *2x + 4 = 2(x + 2)*.
5. *(x + 1)² = x² + 1*.

---

## Strong ★★

Докажи:
6. *(a + b)² + (a − b)² = 2a² + 2b²*.
7. *a² − b² = (a − b)(a + b)*.
8. *(x + 2)² − (x − 2)² = 8x*.
9. *(a + b + c)² = a² + b² + c² + 2ab + 2ac + 2bc*.
10. *5(2x − 3) − 3(x − 5) = 7x*.

Опровергни:
11. *3x − 2 = 5* — это тождество?
12. *a² ≥ 0* — это тождество?
13. *(x − 1)² ≥ 0* — тождество ли?

---

## Advanced ★★★

14. Докажи: *a² + b² + c² ≥ ab + bc + ca* при любых *a, b, c*. *(Подсказка: умножь на 2 и сгруппируй квадраты разностей.)*
15. Докажи: *(a + b + c)² = (a + b − c)² + 4c(a + b)*. *(Раскрой обе части.)*
16. *a² − b² = (a − b)(a + b)*. **Используй для разложения**: *(2x + 1)² − (x + 3)²*.
17. Докажи: *n² + (n + 1)² + n²(n + 1)² = (n² + n + 1)²*. *(Сложно, но красиво.)*

---

## ★★★★ Sphinx Challenge

18. **Зеркало Истины.**
Покажи, что *(a + b + c)(a + b − c) = (a + b)² − c²*.

И вторая часть: используя это, найди *2024² − 2023²*.

*(Подсказка: разность квадратов.)*

---

## English with the Bell Fairy 🔔

**Vocabulary**
- *identity, prove, show that, equation*
- *true for all values, true for some values*

**Task.**
> *(a) Prove the identity: (x + 3)² − (x − 3)² = 12x.*
> *(b) Decide whether the equation x² + 1 = 0 has a real solution. Justify.*
> *(c) Lena says: "Every quadratic identity is also an equation." Is she right? Justify.*

> [Перевод для учителя.]
> «(a) Докажи (x + 3)² − (x − 3)² = 12x.
> (b) Имеет ли уравнение x² + 1 = 0 действительное решение?
> (c) Каждое квадратное тождество — это уравнение?»

> **Методическая заметка.**
> (a) Раскрытие: (x²+6x+9) − (x²−6x+9) = **12x**. ✓
> (b) **Нет** — *x²* всегда ≥ 0, значит *x² + 1 ≥ 1 > 0*. Решений нет.
> (c) **Да в широком смысле**: тождество — это уравнение, верное при всех значениях. Но «уравнение» обычно подразумевает поиск **некоторых** корней — поэтому различие важно.

---

## Кошачий факт 🐾

В **Японии** есть пословица: «**Кот всегда прав**». Это **тождество** — оно истинно при **любой** ситуации. А вот «**кот сейчас спит**» — это **уравнение**: иногда верно, иногда нет.

---

## Рефлексия

1. Чем тождество отличается от уравнения?
2. Можно ли «опровергнуть» тождество одним числом?
3. Какое тождество тебе показалось самым красивым?

## Домашний квест 🌙

1. Докажи *3(x + 5) = 3x + 15*. *(★)*
2. Тождество ли *2x + 4 = x + 6*? Если да — докажи; если нет — найди *x*. *(★★)*
3. Докажи: *(a + 2)² − (a − 2)² = 8a*. *(★★)*
4. Докажи: *a² + b² ≥ 2ab* при любых *a, b*. *(★★★)*
5. **Бонус-квест.** Нарисуй *Зеркало Истины*: с одной стороны равенство истинно, с другой — нет.
