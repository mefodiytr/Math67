# Урок 9.4 — Частотные таблицы

> Длительность: 90 мин. Куратор: Манэки.

## Сюжет

Манэки разворачивает **карту созвездий**. На ней — сколько звёзд каждого типа.

— *Если данных **много**, считай **частоты**,* — говорит он.

## Идея

**Частотная таблица** — это таблица «значение → сколько раз встретилось».

| Значение | Частота |
|---|---|
| 1 | 3 |
| 2 | 5 |
| 3 | 4 |
| 4 | 2 |

Это компактнее, чем выписывать все 14 чисел.

## Среднее по частотной таблице

$$ \bar{x} = \frac{\sum (x \cdot f)}{\sum f} $$

Пример: (1·3 + 2·5 + 3·4 + 4·2) / (3+5+4+2) = (3+10+12+8)/14 = 33/14 ≈ 2.36.

## Группированные данные

Если данных **очень много**, группируют **в интервалы**:

| Интервал | Частота |
|---|---|
| 0–10 | 5 |
| 10–20 | 8 |
| 20–30 | 3 |

> Среднее берётся через **середины** интервалов.

## Кошачий факт 🐾

В **переписи населения Японии** возраст граждан **группируют по 5 лет**: 0–4, 5–9, ... — так удобнее видеть структуру.

## Рефлексия

1. Когда удобна **частотная таблица**?
2. Что **теряется** при группировке?

## Домашка

1. Сколько наблюдений: 1→2, 2→3, 3→1. *(★)*
2. Мода: 4→1, 5→3, 6→2. *(★)*
3. Среднее: 2→3, 4→2, 6→1. *(★★)*
4. Группированная: 0–10 → 4, 10–20 → 6. Среднее (через середины 5 и 15). *(★★★)*

**Часть I:** 1) 14. 2) 2. 3) 5·2+6·3+7·1 = 10+18+7 = 35. 4) 35/6 ≈ 5.83.

**Часть II:** 5) (3·2+4·5+5·3)/10 = 41/10 = 4.1. 6) 5−3 = 2. 7) 2→1, 3→2, 4→3, 5→1. 8) 4 (7 чисел, 4-е по порядку).

**Часть III:** 9) (12·5 + 17·8 + 22·7) / 20 = (60+136+154)/20 = 350/20 = 17.5. 10) Сместится в сторону этой группы.

**Sphinx:** Среднее (3·4 + 5·7 + 7·6 + 9·3)/20 = (12+35+42+27)/20 = 116/20 = 5.8. Мода = 5. Размах = 9−3 = 6.
