# Урок 9.9 — Дерево вероятностей

> Длительность: 90 мин. Куратор: Куро.

## Сюжет

Куро в шляпе детектива чертит **дерево из света**.

— *Если события **последовательно**, рисуй **дерево**. На каждой ветви — **вероятность**. **Перемножай** вдоль пути.*

## Идея

**Дерево вероятностей**:
- Каждый **уровень** — один эксперимент.
- Каждая **ветвь** — исход с вероятностью.
- Сумма вероятностей **выходящих из узла** = 1.
- Вероятность **пути** = произведение его вероятностей.
- Вероятность **события** = сумма путей, ведущих к нему.

## Пример: 2 монеты

```
       О (1/2) ── О (1/2) → ОО, P = 1/4
      /
   старт
      \
       Р (1/2) ── О (1/2) → РО, P = 1/4
                ── Р (1/2) → РР, P = 1/4
```

Все 4 исхода: ОО, ОР, РО, РР, каждый по 1/4.
P(хотя бы 1 орёл) = 3/4.

## Пример: мешок без возврата

Мешок: 3 красных, 2 синих. Тянем 2.
- 1-й раз: P(К) = 3/5, P(С) = 2/5.
- Если 1-й К → осталось 2К, 2С → 2-й P(К) = 2/4.
- Если 1-й С → осталось 3К, 1С → 2-й P(К) = 3/4.

P(оба К) = 3/5 · 2/4 = 6/20 = 3/10.

## Кошачий факт 🐾

В **искусственном интеллекте** деревья вероятностей называют **байесовскими сетями**. На них основаны фильтры **спама** в почте и **диагностика** в медицине.
