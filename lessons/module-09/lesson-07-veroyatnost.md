# Урок 9.7 — Понятие вероятности

> Длительность: 90 мин. Куратор: Цукико.

## Сюжет

Цукико достаёт **серебряную монету**.

— *Бросаю — выпадет **орёл** или **решка**. **Каков шанс**?*

## Идея

**Вероятность** события A:
$$ P(A) = \frac{\text{число благоприятных исходов}}{\text{общее число исходов}} $$

Условия:
- Все исходы **равновероятны**.
- Они **взаимоисключающие**.
- Покрывают **всё** пространство.

**Свойства:**
- 0 ≤ P(A) ≤ 1.
- P(A) = 0 — невозможное.
- P(A) = 1 — достоверное.

## Примеры

1. **Монета**: P(орёл) = 1/2.
2. **Кубик**: P(6) = 1/6.
3. **Кубик чёт**: P({2,4,6}) = 3/6 = 1/2.
4. **Колода 52**: P(туз) = 4/52 = 1/13.
