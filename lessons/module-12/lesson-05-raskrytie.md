# Урок 12.5 — Раскрытие скобок (двучлен × двучлен)

> Длительность: 90 мин. Куратор: Хана.

## Сюжет

Хана пускает **лепесток скобок** — он раскрывается на четыре лепестка.

— *Двучлен × двучлен — это **четыре произведения**.*

## Идея

**FOIL** (англ. First-Outer-Inner-Last):
$$ (a + b)(c + d) = ac + ad + bc + bd $$

**По-русски**: каждое из первой скобки умножай на каждое из второй.

## Пример

$(x + 3)(x + 5) = x² + 5x + 3x + 15 = x² + 8x + 15$.

## Часть I — Раскрыть (★)

1. (x + 1)(x + 2).
2. (x − 1)(x + 4).
3. (a + b)(a − b).
4. (x − 5)(x − 2).

## Часть II — Strong (★★)

5. (2x + 3)(x + 1).
6. (x − 3)(2x + 5).
7. (a + 2b)(a − 2b).
8. (3x + 1)².

## Часть III — Advanced (★★★)

9. (x + 1)(x + 2)(x + 3) (по шагам).
10. (a + b)³ (через (a+b)·(a+b)²).

## ★★★★ Sphinx

11. Хана: *«Найди коэффициент при x в раскрытии (x − 1)(x − 2)(x − 3)».*

## English

> *(a) Expand (x + 4)(x − 3).*
> *(b) Expand (a + b)(a − b).*
> *(c) Expand (x + 1)².*

> [Перевод: «(a)/(b)/(c) раскрой.»]

## Кошачий факт 🐾

В **геометрической интерпретации** (a+b)·(c+d) — это **площадь прямоугольника**, разделённого на **4 части**. Алгебра = **геометрия чисел**.

## Рефлексия

1. Сколько произведений в (a+b)(c+d)?
2. Что такое **FOIL**?

## Домашка

1. (x+2)(x+3). *(★)*
2. (x−1)(x+1). *(★)*
3. (2x+1)(3x−1). *(★★)*
4. Бонус: (x+1)(x²−x+1). *(★★★)*

<details><summary>Ответы</summary>

**Часть I:** 1) x²+3x+2. 2) x²+3x−4. 3) a²−b². 4) x²−7x+10.

**Часть II:** 5) 2x²+5x+3. 6) 2x²−x−15. 7) a²−4b². 8) 9x²+6x+1.

**Часть III:** 9) (x+1)(x+2)=x²+3x+2; ·(x+3) = x³+3x²+2x+3x²+9x+6 = x³+6x²+11x+6. 10) (a+b)·(a²+2ab+b²) = a³+3a²b+3ab²+b³.

**Sphinx:** (x−1)(x−2)(x−3): сначала (x−1)(x−2) = x²−3x+2. Умножим на (x−3): (x²−3x+2)(x−3) = x³−3x²−3x²+9x+2x−6 = x³−6x²+11x−6. Коэффициент при x = **11**.

**English:** (a) x²+x−12. (b) a²−b². (c) x²+2x+1.

**Домашка:** 1) x²+5x+6. 2) x²−1. 3) 6x²+x−1. 4) (x+1)(x²−x+1) = x³+1.

</details>
