# Урок 12.9 — Факторизация многочленов

> Длительность: 90 мин. Куратор: Сфинкс.

## Сюжет

Сфинкс показывает **решётку факторов**.

— *Факторизация — это **обратное** к раскрытию. Несколько **методов**.*

## Идея

**Факторизация** многочлена — представление в виде **произведения**.

**Полный набор методов**:
1. **Вынесение** общего множителя.
2. **Разность квадратов** a²−b² = (a−b)(a+b).
3. **Квадрат суммы/разности** a²±2ab+b² = (a±b)².
4. **Группировка**.
5. **Подбор корня** + деление.

## Алгоритм для x² + bx + c

Найти числа **u, v** такие, что:
- u + v = b.
- u · v = c.

Тогда **x² + bx + c = (x + u)(x + v)**.

## Пример

$x^2 + 5x + 6 = ?$

Нужны u + v = 5, uv = 6 → u=2, v=3.
$x^2 + 5x + 6 = (x+2)(x+3)$.

> *Подсказка: добавь и вычти **4x²**.*

## English

> *(a) Factorise x² + 6x + 9.*
> *(b) Factorise x² − x − 12.*
> *(c) Factorise x⁴ − 16.*

> [Перевод: «(a)/(b)/(c) разложи.»]

## Кошачий факт 🐾

В **алгоритмах шифрования RSA** разложение огромного числа **на простые множители** — **невозможно** за разумное время. На этом стоит **современный интернет**.
