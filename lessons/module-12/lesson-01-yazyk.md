# Урок 12.1 — Алгебра как язык

> Первый урок Модуля 12. Длительность: 90 мин. Куратор: Цукико.

## Сюжет

Лена ступает на **первый камень** Моста Алой Луны. Цукико разворачивает **свиток языка**.

— *Алгебра — это **язык математики**. На нём говорят **формулами**. Каждый символ имеет **смысл**.*

## Идея

**Алгебра** = **арифметика с переменными**.

| Арифметика | Алгебра |
|---|---|
| 2 + 3 = 5 | a + b = c |
| 12 / 4 = 3 | x / y = z |
| Конкретно | Общий случай |

Алгебра позволяет **сказать общее правило**, не **повторяя пример**.

## Из слов в формулу

| По-русски | На алгебре |
|---|---|
| «На 5 больше, чем x» | x + 5 |
| «В 3 раза меньше y» | y / 3 |
| «Сумма квадратов» | a² + b² |
| «Удвоить и прибавить 1» | 2x + 1 |
| «Половина суммы» | (a + b) / 2 |

## Из формулы в слова

| Алгебра | По-русски |
|---|---|
| 3x − 2 | Утроить x и отнять 2 |
| (x + 1)² | Квадрат суммы x и 1 |
| n / 2 | Половина n |
| 5x + 7 | Пять «иксов» плюс 7 |
