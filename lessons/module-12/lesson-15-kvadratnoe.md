# Урок 12.15 — Квадратные уравнения

> Длительность: 90 мин. Куратор: Сфинкс.

## Сюжет

Сфинкс приносит **корни истины** — два кристалла.

— *Квадратное уравнение даёт **до двух** корней.*

## Идея

**Квадратное уравнение**: ax² + bx + c = 0, где a ≠ 0.

**Способы решения** (на 6-м классе):

### 1. Через факторизацию
Разложить на множители; ответ — где **каждый множитель = 0**.

### 2. Через корень из квадрата
x² = N → x = ±√N.

### 3. Через формулу (для следующих лет)
$$ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} $$

## Пример (факторизация)

> $x^2 - 5x + 6 = 0$.

Разложим: (x − 2)(x − 3) = 0.
x − 2 = 0 → x = 2.
x − 3 = 0 → x = 3.

**Корни**: 2 и 3.

## Часть I — Решить (★)

1. x² = 9.
2. x² = 25.
3. x² − 4 = 0.
4. x² − 1 = 0.

## Часть II — Strong (★★)

5. x² − 5x + 6 = 0.
6. x² + 7x + 12 = 0.
7. x² − x − 6 = 0.
8. x² − 2x = 0.

## Часть III — Advanced (★★★)

9. x² + 4x + 3 = 0.
10. x² − 6x + 9 = 0. Сколько корней?

## ★★★★ Sphinx

11. Сфинкс: *«Найди **сумму корней** уравнения **x² − 7x + 12 = 0**, не решая его».*

## English

> *(a) Solve x² = 16.*
> *(b) Solve x² − 4x + 3 = 0.*
> *(c) Find roots of x² − 9 = 0.*

> [Перевод: «(a)/(b)/(c) реши.»]

## Кошачий факт 🐾

В **формуле Виета** (1591) для x² + bx + c = 0 корни x₁, x₂ дают:
- x₁ + x₂ = −b.
- x₁ · x₂ = c.

Это **первая магия** алгебры **8 класса**!

## Рефлексия

1. Сколько может быть **корней**?
2. Когда **один** корень?

## Домашка

1. x² = 49. *(★)*
2. x² − 16 = 0. *(★)*
3. x² − 7x + 10 = 0. *(★★)*
4. Бонус: x² + 8x + 16 = 0. *(★★★)*

**Часть III:** 9) (x+1)(x+3)=0 → −1 и −3. 10) (x−3)² = 0 → x = 3 (один корень).
