# Урок 12.13 — Системы уравнений (алгебраически)

> Длительность: 90 мин. Куратор: Куро.

## Сюжет

Куро поднимает **стрелу подстановки**.

— *Графика — наглядно. Алгебра — **точно**. **Подстановка** или **сложение**.*

## Идея

**Метод подстановки**:
1. Из одного уравнения **выразить** переменную.
2. **Подставить** в другое.
3. **Решить** простое уравнение.
4. **Найти** вторую переменную.

**Метод сложения** (или вычитания):
1. **Умножить** уравнения на коэффициенты.
2. **Сложить** так, чтобы одна переменная **исчезла**.
3. Решить остаток.

## Пример (подстановка)

$$ \begin{cases} x + y = 7 \\ 2x - y = 5 \end{cases} $$

Из 1-го: y = 7 − x.
Во 2-е: 2x − (7−x) = 5 → 3x = 12 → x = 4.
y = 7 − 4 = 3.
**(4, 3).**

## Пример (сложение)

Сложим напрямую: 3x = 12 → x = 4. Тот же ответ.

## Часть I — Подстановкой (★)

1. x + y = 5, x = 2.
2. y = 2x, x + y = 9.
3. y = x + 1, x − y = −1. (Сколько решений?)
4. x = 3, x + y = 7.

## Часть II — Strong (★★)

5. x + y = 10, x − y = 2.
6. 2x + y = 7, x − y = 2.
7. y = 2x, 3x − y = 4.
8. x + 2y = 8, 2x − y = 1.

## Часть III — Advanced (★★★)

9. 3x + 2y = 12, x + y = 5.
10. 5x − 3y = 1, 2x + y = 11.

## ★★★★ Sphinx

11. Куро: *«Найди x, y, z для системы:
$$ \begin{cases} x + y = 5 \\ y + z = 7 \\ x + z = 6 \end{cases} $$»*

## English

> *(a) Solve x + y = 8, x − y = 2.*
> *(b) Solve y = 3x, x + y = 12.*
> *(c) Solve 2x + y = 5, x − y = 1.*

> [Перевод: «(a)/(b)/(c) реши.»]

## Кошачий факт 🐾

В **компьютере** **матрица** систем (вроде наших) решается за **миллисекунды**, но **алгоритмы** — те же: подстановка, сложение, **исключение Гаусса**.

## Рефлексия

1. Когда **подстановка** удобнее?
2. Когда **сложение** удобнее?

## Домашка

1. x + y = 6, x − y = 2. *(★)*
2. y = x + 1, 2x + y = 7. *(★)*
3. 2x + y = 5, x + 2y = 4. *(★★)*
4. Бонус: 3x − 2y = 5, 2x + y = 8. *(★★★)*

<details><summary>Ответы</summary>

**Часть I:** 1) (2, 3). 2) (3, 6). 3) ∞ (тождество). 4) (3, 4).

**Часть II:** 5) (6, 4). 6) Сложить: 3x = 9 → (3, 1). 7) y = 2x, 3x − 2x = 4 → (4, 8). 8) Из 2-го: y = 2x − 1. В 1-е: x + 2(2x−1) = 8 → 5x = 10 → (2, 3).

**Часть III:** 9) Из 2-го: y = 5 − x. В 1-е: 3x + 2(5 − x) = 12 → x = 2, y = 3. (2, 3). 10) Из 2-го: y = 11 − 2x. В 1-е: 5x − 3(11 − 2x) = 1 → 11x = 34 → x = 34/11, y = 11 − 68/11 = 53/11. (34/11, 53/11).

**Sphinx:** Сложить все: 2(x+y+z) = 18 → x+y+z = 9. Тогда z = 9−5 = 4, x = 9−7 = 2, y = 9−6 = 3. **(2, 3, 4)**.

**English:** (a) (5, 3). (b) (3, 9). (c) (2, 1).

**Домашка:** 1) (4, 2). 2) (2, 3). 3) Из 1-го: y = 5−2x. В 2-е: x + 10 − 4x = 4 → x = 2, y = 1. (2, 1). 4) Из 2-го: y = 8 − 2x. В 1-е: 3x − 2(8 − 2x) = 5 → 7x = 21 → x = 3, y = 2. (3, 2).
