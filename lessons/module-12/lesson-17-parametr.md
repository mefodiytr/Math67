# Урок 12.17 — Задачи с параметром. Max / min

> Длительность: 90 мин. Куратор: Кицунэ.

## Сюжет

Кицунэ кладёт **перо историй** на 17-й камень.

— *Параметр — это **скрытая переменная**. Задача с параметром — **семья задач**.*

## Идея

**Параметр** — буква, **значение** которой не задано: a, b, k, m...

**Задача с параметром** = решить **в зависимости** от **a**.

## Пример

> *«Реши уравнение **(a − 1)x = a + 1**».*

| Случай | Ответ |
|---|---|
| a = 1 | 0 = 2 — нет решений |
| a ≠ 1 | x = (a+1)/(a−1) |

## Max / min на параболе

**y = x² + bx + c** имеет **минимум** в **x = −b/2** (вершина).

> y = x² − 6x + 10. Min при x = 3, y = 1.

## Часть I — Параметрические уравнения (★)

1. ax = 5. При каких a — нет решений?
2. ax = 0. Сколько решений?
3. (a + 1)x = 4. При a = −1 — что?
4. ax + 2 = 5. Найди x.

## Часть II — Strong (★★)

5. Реши: ax = a (для всех a).
6. Реши: ax + 1 = a + 1.
7. Найди max y = −x² + 6x − 5.
8. Найди min y = x² + 4x + 5.

## Часть III — Advanced (★★★)

9. При каких a уравнение x² + ax + 1 = 0 имеет **два равных** корня?
10. При каких k прямая y = kx + 1 не пересекает параболу y = x² + 2?

## ★★★★ Sphinx

11. Кицунэ: *«Найди все a, при которых уравнение **x² − 2ax + a² − 1 = 0** имеет **корни 3 и 5**».*

## English

> *(a) Find min of y = x² − 4x + 7.*
> *(b) Solve ax = 5 for all a.*
> *(c) Max of y = −(x − 2)² + 3.*

> [Перевод: «(a) min (b) реши (c) max.»]

## Кошачий факт 🐾

В **физике** **параметрические уравнения** описывают **движение тел**: x(t) = ..., y(t) = .... Параметр **t** — время.

## Рефлексия

1. Что такое **параметр**?
2. Где **вершина** параболы?

## Домашка

1. min y = x². *(★)*
2. min y = (x−3)². *(★)*
3. ax = 7. Когда нет решений? *(★★)*
4. Бонус: max y = −x² + 4x. *(★★★)*

<details><summary>Ответы</summary>

**Часть I:** 1) a = 0 (если правая часть ≠ 0). 2) Если правая часть тоже 0 — все x. Если нет — нет решений. 3) Нет решений (0 ≠ 4). 4) x = 3/a (a ≠ 0).

**Часть II:** 5) Если a ≠ 0: x = 1. Если a = 0: 0 = 0 — все x. 6) (a)x = a → если a ≠ 0: x = 1; если a = 0: 0 = 0. 7) y = −(x−3)² + 4 → max 4 при x = 3. 8) y = (x+2)² + 1 → min 1 при x = −2.

**Часть III:** 9) Дискриминант = 0: a² − 4 = 0 → a = ±2. 10) kx + 1 = x² + 2 → x² − kx + 1 = 0. Дискриминант < 0: k² − 4 < 0 → −2 < k < 2.

**Sphinx:** Корни 3 и 5: x² − (3+5)x + 3·5 = 0 → x² − 8x + 15 = 0. Сравним с x² − 2ax + a² − 1: 2a = 8 → a = 4. Проверка: a² − 1 = 16 − 1 = 15. ✓ **a = 4**.

**English:** (a) 3 (при x=2). (b) Если a ≠ 0: x = 5/a. Если a = 0: нет решений. (c) 3 (при x=2).

**Домашка:** 1) 0. 2) 0. 3) a = 0. 4) y = −(x−2)² + 4 → max 4.
