# Урок 12.8 — Вынесение общего множителя

> Длительность: 90 мин. Куратор: Манэки.

## Сюжет

Манэки вытаскивает **серебряный ключ** — он отпирает **общие множители**.

— *Иногда **общий множитель** прячется. Найди — и **разложи**.*

## Идея

**Вынесение**: a·b + a·c = a · (b + c).

**Что искать**:
1. **Общая буква** во всех слагаемых.
2. **Общее число**.
3. **Общая степень** (наименьшая).

## Пример

> $2x^3 - 4x^2 + 6x = 2x(x^2 - 2x + 3)$.

Общий множитель = 2x.

## Часть I — Вынести (★)

1. 3x + 6.
2. 5y − 10.
3. 4x + 8y.
4. x² + x.

## Часть II — Strong (★★)

5. 2x³ − 4x² + 6x.
6. 6a²b + 9ab² − 3ab.
7. (x + 1) + x(x + 1). *(x+1 — общий!)*
8. x²(x − 2) + 3(x − 2).

## Часть III — Advanced (★★★)

9. x³ + x² − x − 1 *(группировка по 2)*.
10. ax + ay + bx + by *(группировка по 2)*.

## ★★★★ Sphinx

11. Манэки: *«Разложи **a³ − a − 24**».*

> *Подсказка: попробуй a = 3.*

## English

> *(a) Factorise 4x + 12.*
> *(b) Factorise 6x²y − 9xy².*
> *(c) Factorise by grouping: ax + ay + bx + by.*

> [Перевод: «(a)/(b)/(c) разложи.»]

## Кошачий факт 🐾

В **компиляторах** есть оптимизация **«общая подвыражение»**: 2x+3y и 2x+5y делят общую часть **2x** — компилятор её **выносит**.

## Рефлексия

1. Какие **3 типа** общих множителей?
2. Что такое **группировка**?

## Домашка

1. 5x + 15. *(★)*
2. 3a − 6b. *(★)*
3. x³ − x. *(★★)*
4. Бонус: ab + a + b + 1 (по группам). *(★★★)*

<details><summary>Ответы</summary>

**Часть I:** 1) 3(x+2). 2) 5(y−2). 3) 4(x+2y). 4) x(x+1).

**Часть II:** 5) 2x(x²−2x+3). 6) 3ab(2a+3b−1). 7) (x+1)(1+x) = (x+1)². 8) (x−2)(x²+3).

**Часть III:** 9) x²(x+1) − (x+1) = (x+1)(x²−1) = (x+1)(x−1)(x+1) = (x−1)(x+1)². 10) a(x+y) + b(x+y) = (a+b)(x+y).

**Sphinx:** a=3: 27−3−24 = 0. Значит (a−3) — множитель. Деление: a³−a−24 = (a−3)(a²+3a+8). a²+3a+8 — дискриминант 9−32 < 0, неразложимо в R.

**English:** (a) 4(x+3). (b) 3xy(2x−3y). (c) (a+b)(x+y).

**Домашка:** 1) 5(x+3). 2) 3(a−2b). 3) x(x²−1) = x(x−1)(x+1). 4) a(b+1) + (b+1) = (a+1)(b+1).
