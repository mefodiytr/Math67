# Урок 12.16 — Последовательности. Формула n-го члена

> Длительность: 90 мин. Куратор: Бакэнэко.

## Сюжет

Бакэнэко крутит **спираль n-го члена**.

— *Последовательность — это **числа в порядке**. Их **формула** — узор.*

## Идея

**Последовательность**: a₁, a₂, a₃, ..., aₙ.

**Формула n-го члена**: правило, как **по n** найти **aₙ**.

## Виды

1. **Арифметическая прогрессия** (АП): aₙ = a₁ + (n−1)·d.
   - 3, 7, 11, 15, ... → d = 4 → aₙ = 3 + 4(n−1) = 4n − 1.

2. **Геометрическая** (ГП): aₙ = a₁ · q^(n−1).
   - 2, 6, 18, ... → q = 3 → aₙ = 2·3^(n−1).

3. **Квадратичные**: aₙ = an² + bn + c.

## Поиск формулы

Если **разности** равны → линейная (АП).
Если **отношения** равны → ГП.
Если **разности разностей** равны → квадратичная.

## Пример

> 1, 4, 7, 10, 13, ...

Разности: 3, 3, 3, 3 → АП.
a₁ = 1, d = 3.
aₙ = 1 + 3(n−1) = **3n − 2**.

a₅₀ = 3·50 − 2 = **148**.

## Кошачий факт 🐾

В **последовательности Фибоначчи** 1, 1, 2, 3, 5, 8, 13, 21, ... каждый член — **сумма двух предыдущих**. Эта последовательность **повсюду в природе**: лепестки цветов, спирали ракушек.

## Рефлексия

1. Когда **АП**?
2. Что такое **n-й** член?

## Домашка

1. 1, 2, 3, ... aₙ? *(★)*
2. 5, 8, 11, ... aₙ? *(★★)*
3. 100, 200, 400, ... aₙ? *(★★)*
4. Бонус: сумма 1+3+5+...+(2n−1). *(★★★)*

<details><summary>Ответы</summary>

**Часть I:** 1) 2n. 2) 5n. 3) 2^(n−1). 4) n².

**Часть II:** 5) 4n − 1. 6) 6·2^(n−1). 7) n(n+1)/2. 8) 2 + 3·99 = 299.

**Часть III:** 9) 2n − 1. 10) Разности АП с d=2, начиная с 3. aₙ = a₁ + Σ(2k+1) от k=0 до n-2 = 4 + (n−1)² + 2·(n−1)·... уточнение: ряд n²+2 / тщательно: разности 3, 5, 7, 9 — это 2k+1 для k=1,2,3,4. Так что aₙ = 4 + 3 + 5 + ... + (2n−1) = ... вычислимо: aₙ = n² + 3.

**Sphinx:** Сумма АП 3, 5, 7, ..., n=100 → a₁₀₀ = 3 + 2·99 = 201. S = (3 + 201)·100/2 = **10200**.

**English:** (a) 3n+1. (b) 1 + 4·49 = 197. (c) 5050.

**Домашка:** 1) n. 2) 3n+2. 3) 100·2^(n−1). 4) n².
