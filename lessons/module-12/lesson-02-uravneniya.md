# Урок 12.2 — Линейные уравнения (углубление)

> Длительность: 90 мин. Куратор: Цинлун.

## Сюжет

Цинлун ставит **жезл x** на второй камень.

— *Уравнение — это **весы**. Что **слева** = что **справа**.*

## Идея

**Линейное уравнение**: ax + b = 0, где a ≠ 0.

**Корень** (решение): x = −b / a.

## Алгоритм

1. **Раскрой скобки**.
2. **Перенеси переменные** влево, **числа** — вправо (меняй знак).
3. **Приведи** подобные.
4. **Раздели** на коэффициент.
5. **Проверь** подстановкой.

## Пример

**Уравнение**: 3(x − 2) + 4 = 2x + 5.

1. Раскрой: 3x − 6 + 4 = 2x + 5 → 3x − 2 = 2x + 5.
2. Перенос: 3x − 2x = 5 + 2.
3. Приведи: x = 7.
4. Проверка: 3·5 + 4 = 15+4 = 19. 2·7+5 = 19. ✓

## Особые случаи

- **Бесконечно решений**: 0 = 0 (тождество).
- **Нет решений**: 0 = 5 (противоречие).

## Часть I — Решить (★)

1. x + 5 = 12.
2. 2x = 14.
3. 3x − 7 = 14.
4. 5 − x = 2.

## Часть II — Strong (★★)

5. 4x + 3 = 2x + 11.
6. 2(x + 3) = 14.
7. 3(x − 1) = 2x + 5.
8. (x + 1)/2 = 5.

## Часть III — Advanced (★★★)

9. 5(x − 2) − 3(x − 4) = 2(x + 1).
10. (2x − 1)/3 + (x + 1)/4 = 2.

## ★★★★ Sphinx

11. Цинлун: *«Решить уравнение **2(x + a) = ax + 6**, где **a — параметр**».* Реши **в зависимости от a**.

## English

> *(a) Solve 4x − 5 = 11.*
> *(b) Solve 2(x − 3) = x + 1.*
> *(c) Solve 0 = 0. How many solutions?*

> [Перевод: «(a)/(b) реши (c) сколько решений.»]

## Кошачий факт 🐾

В **Древнем Вавилоне** уже **4000 лет назад** решали линейные уравнения — но **без знака равно**. Знак **=** придумал **Роберт Рекорд** в **1557** году.

## Рефлексия

1. Почему «**меняем знак**» при переносе?
2. Что значит «**нет решений**»?

## Домашка

1. 7x = 35. *(★)*
2. 3x + 4 = 19. *(★)*
3. 2(x − 3) = x + 4. *(★★)*
4. Бонус: 5x − 3 = 5(x − 1). *(★★★)*

<details><summary>Ответы</summary>

**Часть I:** 1) 7. 2) 7. 3) 7. 4) 3.

**Часть II:** 5) 2x = 8 → x = 4. 6) x = 4. 7) 3x − 3 = 2x + 5 → x = 8. 8) x = 9.

**Часть III:** 9) 5x − 10 − 3x + 12 = 2x + 2 → 2x + 2 = 2x + 2 → **тождество, ∞ решений**. 10) 4(2x−1) + 3(x+1) = 24 → 8x − 4 + 3x + 3 = 24 → 11x = 25 → x = 25/11.

**Sphinx:** 2x + 2a = ax + 6 → (2 − a)x = 6 − 2a = 2(3 − a). Если a = 2: 0 = 2 — нет решений. Если a ≠ 2: x = 2(3 − a)/(2 − a). Если a = 3: x = 0.

**English:** (a) 4. (b) x = 7. (c) Бесконечно.

**Домашка:** 1) 5. 2) 5. 3) x = 10. 4) 5x − 3 = 5x − 5 → −3 = −5 → нет решений.
