# Урок 12.4 — Степени и их свойства

> Длительность: 90 мин. Куратор: Манэки.

## Сюжет

Манэки взбирается по **бронзовой лестнице** — каждая ступенька **в 2 раза выше** предыдущей.

— *Степени растут **быстро**. Им нужны **правила**.*

## Идея

**Степень**: aⁿ = a · a · ... · a (n раз).

**Свойства**:
1. aⁿ · aᵐ = aⁿ⁺ᵐ.
2. aⁿ / aᵐ = aⁿ⁻ᵐ.
3. (aⁿ)ᵐ = aⁿᵐ.
4. (a · b)ⁿ = aⁿ · bⁿ.
5. (a / b)ⁿ = aⁿ / bⁿ.
6. a⁰ = 1 (a ≠ 0).
7. a⁻ⁿ = 1 / aⁿ.

## Пример

- 2³ · 2⁵ = 2⁸ = 256.
- 3⁶ / 3² = 3⁴ = 81.
- (2³)² = 2⁶ = 64.
- (2·3)² = 2² · 3² = 4·9 = 36.
- 5⁰ = 1.
- 2⁻³ = 1/8.

## Кошачий факт 🐾

В **компьютерах** числа **степени двойки** — особенные: 1024 = 2¹⁰, 1 МБ = 2²⁰ Б. Это **«округление по-программистски»**.
