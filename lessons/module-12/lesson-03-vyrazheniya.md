# Урок 12.3 — Алгебраические выражения

> Длительность: 90 мин. Куратор: Цинлун.

## Сюжет

Цинлун раскрывает **свиток скобок**.

— *Выражение — это **то, что считают**. Уравнение — это **равенство** двух выражений.*

## Идея

**Выражение**: 3x + 5y − 7. Не имеет «=».

**Подобные слагаемые** — те, у которых **одинаковая буквенная часть**: 3x и 7x — подобные. 3x и 3x² — нет.

## Операции

- **Сложение/вычитание**: только подобных.
  - 3x + 5x = 8x.
  - 3x + 5y — не упрощается.
- **Умножение/деление**: с **числами и буквами** отдельно.
  - 2x · 3y = 6xy.
  - (4xy²) / (2y) = 2xy.

## Раскрытие скобок

- a(b + c) = ab + ac.
- −(b + c) = −b − c.
- (a + b)(c + d) = ac + ad + bc + bd.

## Часть I — Упростить (★)

1. 3x + 4x − x.
2. 5y − 2y + y.
3. 2x + 3y + 4x − y.
4. 2(x + 3).

## Часть II — Strong (★★)

5. 3(x − 2) − 2(x + 1).
6. (x + 2)(x + 3).
7. (x − 1)(x + 1).
8. (2x + 3y)(x − y).

## Часть III — Advanced (★★★)

9. 2x · 3x²y / (xy).
10. (a + b)² (раскрой).

## ★★★★ Sphinx

11. Цинлун: *«Сократи: **(x² − 4) / (x − 2)** при **x ≠ 2**».*

## English

> *(a) Simplify 5x + 3 − 2x.*
> *(b) Expand (x + 4)(x − 2).*
> *(c) Combine like terms: 3a + 2b − a + 4b.*

> [Перевод: «(a) упрости (b) раскрой (c) приведи.»]

## Кошачий факт 🐾

В **«стандартной форме»** алгебры выражения **сначала упрощают**, а **потом** работают. Это так же важно, как **причесаться**, прежде чем **выходить**.

## Рефлексия

1. Что такое **подобные** слагаемые?
2. В чём разница **выражения** и **уравнения**?

## Домашка

1. 4x + 2x − x. *(★)*
2. 3(x + 2). *(★)*
3. (x + 1)(x + 4). *(★★)*
4. Бонус: (a − b)². *(★★★)*

<details><summary>Ответы</summary>

**Часть I:** 1) 6x. 2) 4y. 3) 6x + 2y. 4) 2x + 6.

**Часть II:** 5) 3x − 6 − 2x − 2 = x − 8. 6) x² + 5x + 6. 7) x² − 1. 8) 2x² − 2xy + 3xy − 3y² = 2x² + xy − 3y².

**Часть III:** 9) 2x · 3x²y / xy = 6x³y / xy = 6x². 10) a² + 2ab + b².

**Sphinx:** (x² − 4)/(x − 2) = (x − 2)(x + 2)/(x − 2) = **x + 2**.

**English:** (a) 3x + 3. (b) x² + 2x − 8. (c) 2a + 6b.

**Домашка:** 1) 5x. 2) 3x + 6. 3) x² + 5x + 4. 4) a² − 2ab + b².

</details>
