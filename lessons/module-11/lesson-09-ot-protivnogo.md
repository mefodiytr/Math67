# Урок 11.9 — Метод от противного

> Длительность: 90 мин. Куратор: Куро.

## Сюжет

Куро поднимает **перевёрнутый щит**.

— *Если **в лоб** доказать сложно — **предположи обратное**. Получишь **противоречие** — твоё **исходное** верно.*

## Идея

**От противного** (reductio ad absurdum):
1. Хотим доказать P.
2. **Предполагаем ¬P** (что P ложно).
3. Из ¬P **выводим противоречие**.
4. Значит, ¬P **невозможно** ⇒ **P истинно**. ∎

## Знаменитый пример

> *«√2 — иррациональное».*

**Доказательство:**
1. Допустим, √2 = p/q в **несократимом** виде.
2. Тогда 2q² = p² → p² чётное → p чётное.
3. p = 2k → 4k² = 2q² → q² = 2k² → q² чётное → q чётное.
4. Но **p и q оба чётные** — значит, дробь **сократима**.
5. **Противоречие** с пунктом 1. ∎

## Часть I — Простые «от противного» (★)

1. Докажи: **простых чисел бесконечно** много. *(Подсказка: предположим, что их N.)*
2. Если a, b — натуральные и a + b = 0, то они **оба** = 0.
3. Не существует **наибольшего** натурального.
4. Между любыми двумя различными числами есть третье.

## Часть II — Strong (★★)

5. Докажи: если n² чётное, то n чётное (через противное).
6. Докажи: √3 — иррациональное.
7. Докажи: не существует нечётного **простого**, делящегося на 4.
8. Среди 7 человек найдутся двое, родившиеся в один день недели.

## Часть III — Advanced (★★★)

9. Докажи: уравнение n² = 2m² не имеет решений в натуральных n, m. *(Это и есть «√2 иррационален».)*
10. Если a + b = 100 и оба — простые > 2, то они **разной чётности** ... — это невозможно (доказательство).

## ★★★★ Sphinx

11. Куро: *«Среди **5 целых** найдутся **3**, чья сумма **делится на 3**».* Докажи **от противного** (или прямо).

## Кошачий факт 🐾

В **Древней Греции** доказательство **иррациональности √2** так напугало пифагорейцев, что они **скрывали** его — потому что оно противоречило их философии «**всё есть число**».

## Рефлексия

1. Что значит «**противоречие**»?
2. Когда метод **от противного** удобнее?

## Домашка

1. Докажи от противного: «Между 2 и 3 нет натуральных». *(★)*
2. Докажи: если n²=4, то n=2 или n=−2 (от противного). *(★★)*
3. Не существует **наибольшего простого**. *(★★)*
4. Бонус: √5 иррационально. *(★★★)*

<details><summary>Ответы</summary>

**Часть I:** 1) Допустим, простых конечно: p₁,...,p_N. Рассмотрим N = p₁·...·p_N + 1. Оно не делится ни на одно из p_i. Значит, N простое или имеет простой делитель, не из списка. Противоречие. 2) Если a > 0 → b = −a < 0. Но b натуральное → ≥ 0. Противоречие. 3) Допустим max = M. Тогда M+1 > M. Противоречие. 4) (a+b)/2.

**Часть II:** 5) Если n нечётное, то n² нечётное (по правилам). Противоречие. 6) Аналогично √2: n² = 3m² → 3|n² → 3|n. И т.д. 7) Любое > 2 простое → нечётное → не делится на 4. 8) 7 в 7 ящиках — но если все разные, противоречия нет. Подождём: 7 человек в 7 дней — может быть по одному. Уточним: тогда **8 человек** будет с двумя в один день. **Опрос: формулировка должна быть «8 человек».**

**Часть III:** 9) Допустим n² = 2m² с n, m натуральными. Тогда n чётное → n = 2k → 4k² = 2m² → m² = 2k² → m чётное. Бесконечный спуск (или сокращение): противоречит несократимости. 10) Простые > 2 нечётны → сумма нечётно+нечётно = чётное. 100 чётное. Без противоречия — выбрали неправильный пример. Принимай в виде: **a+b = 99** (нечётное); тогда среди простых >2 нет такой пары (оба нечётны → сумма Ч). Противоречие.

**Sphinx:** Среди 5 целых по остаткам ÷3 — рассмотрим случаи. Если **3 имеют один и тот же остаток** — их сумма ⋮ 3. Если **остатки распределены 0,1,2** — значит есть по одному в каждой группе, и сумма представителей: 0+1+2 = 3 ⋮ 3. ∎

**English:** (a)–(c) Доказательства как в уроке.

**Домашка:** 1) Допустим, есть n с 2 < n < 3, целое — невозможно. 2) Если n ≠ ±2, то n² ≠ 4. 3) Аналог Эвклида. 4) √5 = p/q → 5q² = p² → 5|p → p=5k → q²=5k² → 5|q. Противоречие.
