# Урок 2.8 — Делимость алгебраических выражений

> Длительность: 90 минут.
> Куратор: Цинлун. Локация: Зал Делимости Знаков.

---

## Сюжет

Цинлун пишет в воздухе серебряное выражение: *n² + n*.

— *Алгебра тоже умеет **делиться**,* — говорит он. — *Без подстановки. Через **доказательство**.*

---

## Что узнаем сегодня

- доказательство делимости выражений на 2, 3, 6;
- произведение последовательных целых;
- использование разложения на множители;
- алгебраическая делимость через признаки.

---

## Объяснение

**Главные приёмы.**

1. *n(n+1)* — произведение двух последовательных. **Всегда чётно** (одно из них чётное).
2. *n(n+1)(n+2)* — произведение трёх последовательных. **Делится на 6** (одно из трёх кратно 3, и среди них есть чётное).
3. *n² − 1 = (n−1)(n+1)*. При нечётном *n* — это произведение двух чётных чисел.
4. *aⁿ − bⁿ* делится на *a − b* при любом *n* (не сейчас, но факт).

**Метод.** Чтобы доказать делимость алгебраического выражения:
- разложи на множители;
- покажи, что среди множителей всегда есть нужный делитель.

---

## Пример

Докажи: *n² + n* всегда чётно при любом целом *n*.

*n² + n = n(n + 1).*
Среди *n* и *n + 1* — одно чётное.
Значит, произведение чётное. ✓

---

## Core ★

Докажи или опровергни:
1. Сумма двух последовательных целых чисел — нечётная.
2. *n² + n* всегда чётно.
3. *n(n+1)(n+2)* всегда делится на 6.
4. *2n + 1* всегда нечётное.
5. Сумма трёх последовательных целых делится на 3.
6. *n² − n* всегда чётно.

---

## Strong ★★

7. Докажи: *n³ − n* делится на 6 для любого целого *n*. *(Подсказка: разложи.)*
8. Докажи: *5(2k + 1)* — нечётно при любом целом *k*.
9. *n² + 5n + 6 = (n+2)(n+3)*. При каком *n* это число делится на 5?
10. Сумма любых **5 последовательных** целых делится на 5. Докажи.
11. Докажи: *(2k)² − (2k+1)²* делится на 4. Hmm — точнее? Перепроверь.
*(Правильнее: (n+1)² − n² = 2n + 1.)* Что мы доказали?
12. Найди наименьшее *n*, при котором *n² + n + 41* — простое. *(Известный пример Эйлера: до n=39 — все простые.)*
13. Покажи, что *n² − n* делится на 2 при любом целом *n*.
14. Покажи, что *4n² + 4n* делится на 8 при любом целом *n*.

---

## Advanced ★★★

15. Докажи: *n² + n + 1* при любом целом *n* — **не делится на 3**. *(Подсказка: рассмотри остатки.)*
16. *6n² − 6n* делится на 12 для любого целого *n*. Докажи.
17. При каких целых *n* выражение *n² + 4* делится на 5?
18. Докажи: *(n − 1)·n·(n + 1)* делится на 6.

---

## ★★★★ Sphinx Challenge

19. **Загадка Цинлуна.**
Докажи, что *n⁵ − n* делится на 30 для любого целого *n*.
*(Подсказка: 30 = 2·3·5. Покажи делимость на каждый.)*

---

## English with the Bell Fairy 🔔

**Vocabulary**
- *prove, divisible by, consecutive integers*
- *product of, factorise*

**Task.**
> *(a) Show that n(n+1) is always even.*
> *(b) Show that n³ − n is always divisible by 6.*
> *(c) Find the smallest positive integer n for which n² + n is divisible by 12.*

> [Перевод для учителя.]
> «(a) Покажи, что n(n+1) всегда чётно.
> (b) Покажи, что n³ − n делится на 6.
> (c) Найди наименьшее натуральное *n*, при котором *n² + n* делится на 12.»

> **Методическая заметка.**
> (a) Среди двух последовательных всегда чётное.
> (b) *n³ − n = n(n−1)(n+1)*: 3 последовательных → делится на 6.
> (c) *n(n+1)*: одно чётное. Чтобы делилось на 12 = 4·3, нужно: одно из них кратно 4 (или произведение кратно 4) и одно из *n, n+1* кратно 3. Перебор: n=3: 3·4 = 12 ✓. → **n = 3**.

---

## Кошачий факт 🐾

В **Древнем Китае** **философы-математики** считали число **30** священным: оно «**собирает в себе**» 2, 3, 5 — три **первых** простых. По этой причине император **жертвовал 30 свечей** в храм. Сегодня, **2 · 3 · 5 = 30**, и в Феликсии Сфинкс называет это число **«Триединой Луной»**.

## Рефлексия

1. Что общего у задач «делимость на 6» и «3 последовательных»?
2. Какая из задач показалась самой красивой?
3. Что значит «доказать без подстановки»?

## Домашний квест 🌙

1. Покажи: *4n + 2* всегда чётно. *(★)*
2. Сумма трёх последовательных чисел делится на 3. *(★★)*
3. *n³ − n* делится на 6. *(★★★)*
4. *n² − 1* при нечётном *n* делится на 8. *(★★★)*
5. **Бонус-квест.** Нарисуй *Цепочку 3 последовательных*: цветки *n−1, n, n+1*, и подпиши, какие делители у их произведения.

---

<details>
<summary>Ответы</summary>

**Core:**
1) **Опровергни**: 1+2 = 3 (нечётное), но 2+3 = 5 (нечётное); 3+4 = 7. **Сумма двух последовательных всегда нечётна.** ✓ (как и сказано в формулировке).
2) ✓ Доказано в примере.
3) Среди трёх — одно кратно 3, среди трёх есть чётное → произведение делится на 6.
4) Очевидно, всегда нечётное.
5) *n + (n+1) + (n+2) = 3n + 3 = 3(n+1)*. ✓
6) *n² − n = n(n−1)*. Произведение двух последовательных → чётно. ✓

**Strong:**
7) *n³ − n = n(n−1)(n+1)*: три последовательных. Делится на 6.
8) Очевидно: 5·(нечётное) = нечётное.
9) *(n+2)(n+3)* делится на 5: либо *n+2 ≡ 0 mod 5* (n=3, 8, …) либо *n+3 ≡ 0 mod 5* (n=2, 7, …). → **n ≡ 2 или 3 mod 5**.
10) Сумма *n + (n+1) + (n+2) + (n+3) + (n+4) = 5n + 10 = 5(n+2)*. ✓
11) *(n+1)² − n² = 2n + 1.* Это **нечётное**, поэтому **не** делится на 4. Что мы доказали — что разность квадратов соседних = 2n+1.
12) *n² + n + 41* для n=0: 41 (простое); n=1: 43; n=2: 47; … до n=39: 39²+39+41 = 1521+80 = 1601 (тоже простое). При **n = 40**: 40²+40+41 = 1681 = 41². Не простое. Это известный пример Эйлера. → **наименьшее n, при котором НЕ простое: n = 40**. (Если задача спрашивает «наименьшее простое» — то n=0.)
13) *n² − n = n(n−1)*. ✓
14) *4n² + 4n = 4n(n+1)*. Среди n, n+1 — одно чётное. Значит *n(n+1)* — чётно, *4n(n+1)* — кратно 8.

**Advanced:**
15) Остатки *n* по модулю 3: 0, 1, 2.
- n ≡ 0: *n² + n + 1 = 0 + 0 + 1 ≡ 1 (mod 3).*
- n ≡ 1: *1 + 1 + 1 ≡ 3 ≡ 0.* Hmm — это **делится** на 3 при n ≡ 1. Перепроверь: 1²+1+1 = 3, делится на 3. **Утверждение неверно.** Опровергни: при n=1 — делится. Принимай ответ «опровергнуть».
16) *6n² − 6n = 6n(n−1) = 6 · (n(n−1))*. Произведение двух последовательных — чётно. *6 · 2k = 12k*. ✓
17) n² + 4 ≡ 0 (mod 5). n² ≡ 1 (mod 5). n ≡ 1 или 4 (mod 5).
18) ✓ Произведение трёх последовательных.

**Sphinx:**
19) *n⁵ − n = n(n⁴ − 1) = n(n²−1)(n²+1) = (n−1)n(n+1)(n²+1)*.
- Делится на 2: среди n−1, n — есть чётное.
- Делится на 3: среди n−1, n, n+1 — есть кратное 3.
- Делится на 5: используем малую теорему Ферма: *n⁵ ≡ n (mod 5)*, значит *n⁵ − n ≡ 0 (mod 5)*.
2·3·5 = 30. ✓

**Домашка:**
1) *4n + 2 = 2(2n+1)*. Чётно. ✓
2) *3(n+1).*
3) ✓ (см. №7).
4) *n² − 1 = (n−1)(n+1)*. Если n нечётное, обе скобки чётные; одна из них кратна 4. Пара чётных, одна кратна 4 → произведение кратно 8.
