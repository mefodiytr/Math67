# Урок 2.11 — Доказательства делимости

> Длительность: 90 минут.
> Куратор: Куро. Локация: Зал Доказательств.

---

## Сюжет

Куро ведёт Лену в маленький круглый зал с белыми стенами. На стенах висят **рамки**. В каждой — утверждение и **место для доказательства**.

— *Истина — это не то, что **видно**. Это то, что **доказано**,* — говорит Куро. — *Сегодня мы пишем настоящие доказательства.*

## Что узнаем сегодня

- структура доказательства;
- доказательства делимости через разложение;
- доказательства через остатки;
- доказательство «от противного».

---

## Объяснение

**Структура доказательства делимости.**

1. **Дано:** что нам известно.
2. **Доказать:** что хотим показать.
3. **Решение:**
 - представь выражение в форме *kn* (где *n* — нужный делитель);
 - либо рассмотри все остатки и покажи, что результат всегда даёт нужный.
4. **Q.E.D. / ч.т.д.** (что и требовалось доказать).

**Главные приёмы:**
- разложение на множители;
- идея «n последовательных целых»;
- сравнение по модулю;
- от противного.

---

## Пример

**Утверждение:** Сумма любых трёх последовательных целых делится на 3.

**Доказательство.**
Пусть три последовательных: *n, n+1, n+2*.
Сумма = *n + (n+1) + (n+2) = 3n + 3 = 3(n + 1)*.
*3(n+1)* — кратно 3.
Значит, сумма делится на 3. **Q.E.D.**

---

## Core ★

Докажи или опровергни:
1. Произведение двух последовательных целых чисел чётно.
2. Произведение двух нечётных — нечётно.
3. Сумма двух нечётных — нечётная.
4. Сумма пяти последовательных целых делится на 5.
5. Квадрат любого нечётного числа нечётен.
6. *6n + 9* делится на 3 при любом целом *n*.

---

## Strong ★★

7. Докажи: *4n + 12 — 8m* делится на 4 при любых целых *m, n*.
8. Докажи: разность квадратов двух последовательных целых — нечётная.
9. Докажи: *n³ + 5n* делится на 6 при любом целом *n*.
10. Опровергни: «*n² + 3n + 1* всегда нечётно». *(Найди контрпример.)*
11. Докажи: сумма квадратов трёх последовательных целых даёт остаток 2 при делении на 3.
12. Докажи **от противного**: √2 — иррациональное число. *(Если успеешь, это для подготовки к Модулю 11.)*
13. Докажи: если *n* — нечётное, то *n² − 1* делится на 8.

---

## Advanced ★★★

14. Докажи: для любого простого *p > 3* выражение *p² − 1* делится на 24.
15. Докажи: *5(2n + 1) − 3(2m + 1)* всегда чётно при любых *m, n*.
16. Докажи: если *n* — натуральное и *n²* делится на 3, то и *n* делится на 3. *(От противного.)*
17. Опровергни: «Если *p* — простое, то *2ᵖ − 1* — простое». *(Контрпример: p = 11.)*

---

## ★★★★ Sphinx Challenge

18. **Загадка Куро.**
Докажи: для любых целых чисел *a, b, c* — выражение *a² + b² + c²* **не может** дать остаток 7 при делении на 8.

*(Подсказка: квадраты по модулю 8 дают остатки 0, 1 или 4. Перебери все суммы троек.)*

## English with the Bell Fairy 🔔

**Vocabulary**
- *prove, statement, divisibility, contradiction*
- *show that, hence, therefore, Q.E.D.*

**Task.**
> *(a) Prove that the sum of any 4 consecutive integers is even.*
> *(b) Prove that 4n² + 4n is divisible by 8 for any integer n.*
> *(c) Find a counterexample to the statement: "Every number of the form n² + n + 41 is prime."*

> [Перевод для учителя.]
> «(a) Сумма 4 последовательных чисел чётна.
> (b) *4n² + 4n* делится на 8 при любом целом *n*.
> (c) Контрпример к утверждению: *«n² + n + 41* всегда простое».*»

> **Методическая заметка.**
> (a) Сумма = 4n + 6 = 2(2n+3). Чётно. ✓
> (b) *4n(n+1)*, среди *n, n+1* — чётное → произведение кратно 8.
> (c) При **n = 40**: 40²+40+41 = 1681 = 41². **Не простое.**

**Core:**
1) *n(n+1)*: одно чётное → чётно. ✓
2) *(2k+1)(2m+1) = 4km + 2k + 2m + 1 = 2(2km+k+m) + 1*. Нечётно. ✓
3) *(2k+1) + (2m+1) = 2(k+m+1)*. **Чётно**. **Опровергни:** сумма двух нечётных **чётна**.
4) *5n + 10 = 5(n+2)*. ✓
5) *(2k+1)² = 4k² + 4k + 1 = 2(2k²+2k) + 1*. Нечётно. ✓
6) *6n + 9 = 3(2n + 3)*. ✓

**Strong:**
7) *4n + 12 − 8m = 4(n + 3 − 2m)*. ✓
8) *(n+1)² − n² = 2n + 1*. Нечётно. ✓
9) *n³ + 5n = n(n² + 5)*. Если *n* чётное — n³ чётно, 5n чётно, сумма чётна. На 3: n² + 5 ≡ ?. n=0: 5 mod 3 = 2; n=1: 6 mod 3 = 0; n=2: 9 mod 3 = 0. Лучше: n³+5n = n³−n + 6n = (n−1)n(n+1) + 6n. Первое — 3 последовательных → кратно 6. Второе — 6n → кратно 6. Сумма кратна 6. ✓
10) При n=2: 4+6+1 = 11 (нечётно ✓). При n=1: 1+3+1 = 5 (нечётно). При n=4: 16+12+1 = 29 (нечётно). Нужно попробовать чётное и проверить. На самом деле *n² + 3n + 1*: n чётное → n² чётно, 3n чётно, 1 → сумма нечётная. n нечётное → n² нечётно, 3n нечётно, 1 → сумма нечётная. **Утверждение верно**. Опровергнуть нельзя.
11) Сумма *n² + (n+1)² + (n+2)² = 3n² + 6n + 5 = 3(n² + 2n + 1) + 2 = 3(n+1)² + 2*. ≡ 2 (mod 3). ✓
12) **От противного:** допустим *√2 = p/q* в простейшем виде. *p² = 2q²*. Значит *p²* чётное, значит *p* чётное (по №16). *p = 2k → 4k² = 2q² → q² = 2k²* → *q* чётное. Но *p, q* должны быть взаимно простыми — противоречие. ✓
13) *n* нечётное → *n − 1* и *n + 1* — оба чётные, среди них одно кратно 4. *n² − 1 = (n−1)(n+1)* — произведение чётных, одно из которых кратно 4 → кратно 8. ✓

**Advanced:**
14) *p² − 1 = (p−1)(p+1)*. *p* нечётное → обе скобки чётные, одна кратна 4 → кратно 8. *p > 3*, не делится на 3 → одна из *p−1, p+1* кратна 3. → 8·3 = 24. ✓
15) *5(2n+1) − 3(2m+1) = 10n + 5 − 6m − 3 = 10n − 6m + 2 = 2(5n − 3m + 1)*. ✓
16) Допустим, *n* не делится на 3. Тогда *n* = 3k+1 или 3k+2. *n² = 9k² + 6k + 1* (≡ 1 mod 3) или *n² = 9k² + 12k + 4* (≡ 1 mod 3). В обоих случаях *n²* не делится на 3 — противоречие. ✓
17) При *p = 11*: *2¹¹ − 1 = 2047 = 23 · 89*. Не простое. ✓
