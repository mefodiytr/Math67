# lessons/ — полные конспекты уроков

Каждый файл здесь — **подробный конспект одного занятия** для ученицы Лены. Длительность — 90 минут.

## Структура урока

| Часть | Что внутри |
|-------|-----------|
| Сюжет | где Лена, какая загадка, кто из хранителей рядом |
| Что узнаем сегодня | список целей |
| Объяснение | теория с метафорой из мира Феликсии |
| Пример | разбор от лица персонажа |
| **Core ★** | 6–10 базовых задач |
| **Strong ★★** | 8–12 повышенных задач |
| **Advanced ★★★** | 4–6 опережающих |
| **Sphinx ★★★★** | 1–2 олимпиадных |
| English with the Bell Fairy 🔔 | Cambridge-блок: словарь + 3-частная задача + перевод для учителя |
| Кошачий факт / Миф | 60–100 слов японско-китайско-кошачьего фольклора |
| Рефлексия | 3 вопроса для самопроверки |
| Домашний квест 🌙 | 4–5 задач + бонус-квест |
| Ответы | под спойлером `<details>` |

## Связи каждого урока

К каждому уроку **привязаны ещё 3 файла**:

```
lessons/module-NN/lesson-MM-slug.md            ← вы здесь (конспект)
teacher-guides/module-NN/lesson-MM-guide.md    ← методичка с таймингом и разборами
lesson-presentations/module-NN/lesson-MM-slides.md  ← описание слайдов + промты GPT Image
slides/lesson-presentations/module-NN/lesson-MM-slug.pptx  ← готовая презентация (если есть)
```

## Соглашения по именованию

- `lesson-MM-slug.md` — где `MM` — двузначный номер урока внутри модуля (01..18), `slug` — транслитерированный slug (например, `zal-chisel`, `sad-drobei`).
- Финальный урок модуля — обычно `lesson-MM-final.md` или `lesson-MM-tronny-zal.md` / `lesson-MM-bakeneko-polnolunie.md` и т.п.
