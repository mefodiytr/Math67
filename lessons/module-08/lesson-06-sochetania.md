## Сюжет

Хана с корзиной. Она кладёт в неё цветы — **по 3 из 7**. Порядок, в котором она их кладёт, **не важен**.

— *Сочетание — это **выбор без порядка**. *C(n, k) = n!/(k!(n−k)!)*.*

## Что узнаем

- что такое сочетание;
- формула C(n, k);
- разница перестановки vs сочетания;
- задачи на выбор «без порядка».

## Объяснение

**Сочетание** — выбор *k* элементов из *n* **без учёта порядка**.

> *C(n, k) = n! / (k!·(n−k)!)*

**Числитель n!** — все упорядоченные выборы.
**Знаменатель k!** — порядки выбранных, которые мы **не учитываем**.

**Сравнение:**
- Перестановка (порядок): *P(n, k) = n!/(n−k)!*
- Сочетание (без порядка): *C(n, k) = P(n, k)/k!*

## Пример

Из 5 человек выбрать 3 для команды:
- *C(5, 3) = 5!/(3!·2!) = 120/12 = 10*.
