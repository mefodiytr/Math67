# Урок 8.3 — Стол Произведений. Правило умножения

> Длительность: 90 мин. Куратор: Манэки.

## Сюжет

Манэки за столом разложил **сетку** из карточек. На каждой — пара выборов.

— *Если **И** — умножай. Это **правило произведения**.*

## Что узнаем

- правило умножения (правило произведения);
- независимые выборы;
- задачи с несколькими этапами;
- сетка / таблица.

## Объяснение

> **Правило умножения:** если выбор A можно сделать *m* способами, и **независимо** выбор B — *n* способами, то **общее количество** = *m · n*.

**Расширение:** при большем числе **независимых** выборов — все умножаются.

## Пример

Лена выбирает **обед** (3 первых) **И** **напиток** (4 видов): *3·4 = 12* комбинаций.

Лена пишет **3-значный код** из {0..9}: *10·10·10 = 1000* кодов.

## Core ★

1. 5 рубашек × 4 брюк. Сколько комбинаций?
2. Кубик 2 раза. Сколько результатов?
3. 3 цвета × 2 размера × 2 модели. Кол-во?
4. 3-значный код из {0..9} с повторами.
5. 4-значный код с повторами.
6. 6 шапок × 3 шарфа × 2 пары перчаток.

## Strong ★★

7. Лена выбирает чай (4 вида) и сладость (3 вида). Сколько меню?
8. Из 5 слов первые буквы образуют слово. Сколько разных «слов» можно составить из 5 букв (с повторами)?
9. Цвет машины (5) × двигатель (3) × салон (2). Сколько разных машин?
10. 5 человек на 5 разных стульях. Сколько посадок?
11. Подбрасывают 3 монеты. Сколько результатов?
12. Из {1..6} двузначные числа. *(36.)*
13. Из {0..9} коды длины 5 без повторов. *(10·9·8·7·6.)*
14. На скамье 4 девочки и 3 мальчика по очереди. Сколько способов? *(7! = 5 040.)*

## Advanced ★★★

15. 4-значное число делится на 5 (последняя 0 или 5), цифры из {0..9} с повторами, первая ≠ 0. *(9·10·10·2 = 1 800.)*
16. Лена и Цукико выбирают по 1 из 5 чашек. Каждая может выбрать **любую**, в том числе одинаковую. *(5·5 = 25.)*
17. Если **разные**: *5·4 = 20.*
18. 4-значное чётное из {1..9} без повторов. *(Последняя из {2,4,6,8} = 4. Первые 3 из остальных 8 без повторов = 8·7·6 = 336. Всего 4·336 = 1 344.)*
