# Урок 6.9 — Зал Видов треугольников

> Длительность: 90 минут.
> Куратор: Хана. Локация: Зал Видов.

---

## Сюжет

В Зале Видов на стенах висят **разные треугольные колокольчики**: острые, прямые, тупые.

— *Треугольники классифицируют **по углам** и **по сторонам**.*

---

## Что узнаем сегодня

- классификация по углам (острый, прямой, тупой);
- классификация по сторонам (равносторонний, равнобедренный, разносторонний);
- 6 типов треугольников;
- задачи на определение вида.

---

## Объяснение

**По углам:**
- **Остроугольный** — все 3 угла острые.
- **Прямоугольный** — один угол 90°.
- **Тупоугольный** — один угол тупой (>90°).

**По сторонам:**
- **Равносторонний** — все 3 стороны равны (и все углы по 60°).
- **Равнобедренный** — две стороны равны.
- **Разносторонний** — все стороны разные.

**Возможные комбинации:**
| По углам / по сторонам | Разнос. | Равноб. | Равнос. |
|------|-------|---------|---------|
| Остроугольный | ✓ | ✓ | ✓ |
| Прямоугольный | ✓ | ✓ | — |
| Тупоугольный | ✓ | ✓ | — |

(Равносторонний всегда остроугольный — все углы 60°.)

---

## Пример

Треугольник со сторонами 3, 4, 5.
- *3² + 4² = 5²* (9 + 16 = 25). Это **прямоугольный** (по обратной теореме Пифагора).
- Стороны разные → **разносторонний**.
- → **Прямоугольный разносторонний.**

## Кошачий факт 🐾

В **Японии** **колокольчик храма** часто имеет **треугольную** форму звука: основной + 2 обертонa. Это и есть **3 угла треугольника** в звуке — **гармония**.
