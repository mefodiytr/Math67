# Урок 10.13 — Смеси и сплавы

> Длительность: 90 мин. Куратор: Хана.

## Сюжет

Хана разливает **два кувшина**: один с розовым нектаром, второй с белым.

— *Смешиваешь — **смесь**. Главное — **что от чего сохраняется**.*

## Идея

**Смесь = сумма веществ**.

Если смешали **m₁** граммов первого и **m₂** второго:
$$ m_{смеси} = m_1 + m_2 $$

Если в каждом есть **«вещество A»** в количествах **a₁ и a₂**:
$$ a_{смеси} = a_1 + a_2 $$

**Концентрация** (доля) в смеси:
$$ c_{смеси} = \frac{a_1 + a_2}{m_1 + m_2} $$

## Пример

> *«2 кг сахара 30% + 3 кг сиропа 50%. Концентрация смеси?»*

Сахар: 2·0.3 + 3·0.5 = 0.6 + 1.5 = 2.1 кг.
Масса: 5 кг.
c = 2.1/5 = **42%**.

## Кошачий факт 🐾

В **японской косметике** «**сэрум**» (концентрация активного вещества) — точная **математическая** задача: 2% витамина C — обычная, 10% — сильная.

## Рефлексия

2. Зачем **правило креста**?

**Часть I:** 1) 5 кг. 2) 1 кг. 3) (10+30)/200 = 20%. 4) Та же c.

**Часть II:** 5) (5·0.1 + 10·0.4)/15 = 4.5/15 = 30%. 6) (200·0.2 + x·0.4)/(200+x) = 0.3 → 40 + 0.4x = 60 + 0.3x → 0.1x = 20 → x = 200. 7) 40 = 100·0.4. Чистая вода m: 40/(100+m) = 0.2 → m = 100. 8) (100·0.7 + 200·0.4)/300 = 150/300 = 50%.

**Sphinx:** Из 500 г 50% — 250 г вещества. Из первого 300·0.3 = 90 г. Второй — 200 г, в нём 250 − 90 = 160 г → c = 160/200 = **80%**.
