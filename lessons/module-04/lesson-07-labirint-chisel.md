## Объяснение

**Запись числа через цифры.**
- Двузначное число с цифрами *a* (десятки) и *b* (единицы): *10a + b*.
- Трёхзначное *abc*: *100a + 10b + c*.

**Перестановка цифр** даёт **другое** число:
- Двузначное *ab*: *10a + b*.
- После перестановки *ba*: *10b + a*.
- Разница: *10a + b − 10b − a = 9(a − b)*.

**Среднее.**
- *среднее арифметическое = (a + b)/2*.
- Если задано *среднее = m*, то *a + b = 2m*.

---

## Пример

Сумма цифр двузначного числа равна 9. Если поменять цифры местами, число увеличится на 27. Найди число.

- Десятки *a*, единицы *b*. *a + b = 9*.
- Исходное *10a + b*. После *10b + a*. Разность: *9(b − a) = 27 → b − a = 3*.
- *a + b = 9, b − a = 3* → *a = 3, b = 6*.
- Число **36**.

## English with the Bell Fairy 🔔

**Vocabulary**
- *digit, two-digit number, reverse the digits*
- *consecutive integers, sum of digits*

**Task.**
> *(a) The sum of three consecutive integers is 60. Find them.*
> *(b) A two-digit number has digits that sum to 9. The number is 27 less than the number formed by reversing its digits. Find the number.*
> *(c) Lena thinks of a number. She doubles it, adds 8, then divides by 4 — the result is 5. What was her number?*

> [Перевод для учителя.]
> «(a) Сумма трёх последовательных = 60.
> (b) Двузначное, сумма цифр 9, после перестановки — на 27 больше.
> (c) Удвой, +8, ÷4 = 5.»

> **Методическая заметка.**
> (a) 3n+3 = 60 → n = 19. Числа **19, 20, 21**.
> (b) a + b = 9, *10b + a − (10a + b) = 9(b − a) = 27 → b − a = 3*. → a = 3, b = 6. Число **36**.
> (c) (2x + 8)/4 = 5 → 2x + 8 = 20 → **x = 6**.

---

## Кошачий факт 🐾

В **Японии** **двузначные числа** записываются как **дзю-кей** (十-単位): «*десять и единицы*». Поэтому 36 — это **三十六** (3·10 + 6). Это **прямая** запись формулы *10a + b*. Цифры — это **этажи**.
